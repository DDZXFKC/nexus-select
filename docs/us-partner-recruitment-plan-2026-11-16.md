# 米国発送パートナー募集：具体案（2026-11-16）

作成：Claude（オーナーとの相談内容をまとめたもの）／実行：魔王ちゃん
目的：米国（オレゴン優先）で、受け取り・検品・発送をしてくれる個人パートナーを1名決める。

## 1. 決まったこと（オーナー確認済み）

| 項目 | 内容 |
|---|---|
| 報酬 | **1箱10ドル**（1ドル158円で約1,580円）、月末締め・毎月払い |
| 見せ方 | **内職**として出す。1箱の単価ではなく、**時給換算（100ドル以上）**を前面に出す |
| 波の説明 | 件数は月によって変わることを一言書く。最低保証で安心させる |
| 最低保証 | 最初の3か月だけ、件数が少ない月も**月50ドル** |
| 立て替え | なし（商品代金はこちらが直接支払う） |
| 作業時間の目安 | 慣れれば1箱5分ほど（オーナーの実績：1時間に20箱は余裕） |
| 対象 | 限定しない。日本人・日本語話者は歓迎と書く。就労資格には触れない |
| 優先地域 | オレゴン → デラウェア → ニューハンプシャー → モンタナ → その他 |
| 使わない媒体 | Reddit、ロコタビ（手数料・直接取引不可・連絡が回らない）、大学の日本人学生団体の公式窓口（返信ゼロ） |

## 3. 募集文

> **お仕事の流れ**
> 1. ご自宅に届いた商品を開けて、写真を数枚撮って送る
> 2. 梱包して、こちらで用意するラベルを貼る
> 3. 集荷に出す（郵便局へ行く必要はありません）

> - 1箱10ドル、月末締めで毎月お支払い
> - 今後は月20〜30件の見込み（月200〜300ドル程度）
> - 1時間あたりの単価は高めですが、件数は月によって変わります（立ち上げ期は少なめ、最初の3か月は最低50ドル保証）
> - 商品代金の立て替えはありません
>
> 保管なし・通勤なし・ノルマなし。主婦の方、学生の方、副収入がほしい方に向いています。
> 興味のある方は、お住まいのエリアと一言を [連絡先] までどうぞ。

## 4. 応募から開始までの流れ

1. **応募の受付**（魔王ちゃん）：返信はその日のうちに。英語の応募には魔王ちゃんが英語で返す
2. **書面で確認**：住所のエリア（州・市）、平日の在宅時間、写真を撮れるスマホがあるか、支払いの受け取り方法（PayPal・Wiseなど）
3. **顔合わせ（10〜15分、カメラあり）**：Google Meetで行う。オーナーがGoogle AI Proに入っていれば、1対1の通話で同時通訳が使え、オーナーは日本語のまま話せる（相手は無料のままでよい）。本番の前に一度試しておく
4. **テスト1箱**：最初の1件は、作業を動画か写真で記録してもらい、梱包の仕方を確認する
5. **開始**：条件を書面（メール）で送り、相手から了承の返信をもらって開始

### 顔合わせの台本（オーナー用、日本語で話す）

1. あいさつと自己紹介（日本でスニーカー・アパレルを販売していること）
2. 仕事の流れ（受け取り → 写真 → 梱包 → ラベル → 集荷）
3. 報酬（1箱10ドル、毎月払い、最初の3か月は最低50ドル、件数には波がある）
4. 連絡は基本的にメール・チャットの文字で行うこと
5. テストの1箱から始めること、次の連絡の予定
6. 相手からの質問（答えにくいものは「あとで文字で返す」でよい）

細かい条件は通話で決めず、通話のあとに文字で送る。

## 5. 作業手順書（パートナーに渡すもの・魔王ちゃんが作成）

写真つきで1枚にまとめる。日本語・英語の両方。

- 開封のしかた（箱・付属品・タグを捨てない）
- 写真の撮り方（外箱、商品の全体、サイズ表記、気になる傷）
- 梱包のしかた（緩衝材、箱の選び方）
- ラベルの貼り方と集荷の申し込み方
- 追跡番号の報告方法
- 返品が来たときの対応

## 6. 件数が増えたときの見直し

- オーナーの実績では、1日24箱でも作業は1〜2時間。内職の範囲で回る
- 為替が大きく動いたら、1箱10ドルを見直す（半年ごとが目安）
- 月100箱を超えるあたりで、パートナーの2人目、または発送代行業者への移行を検討する
