# 米国発送パートナー募集：具体案（2026-11-16）

作成：Claude（オーナーとの相談内容をまとめたもの）／実行：魔王ちゃん
目的：米国（オレゴン優先）で、受け取り・検品・発送をしてくれる個人パートナーを1名決める。

## 0. 経緯：話し合った内容と、なぜそう決めたか

2026-11-16 早朝、オーナーとClaude（チャット）の相談をまとめたもの。

### 0-1. 出発点
- 米国在住の個人パートナー1名の募集に、反応がゼロだった
- 募集先リスト110件を調査し、連絡先が分かったのは48件。実際に打診したのは、オレゴン大学JSO、ポートランド州立大学SALP、オレゴン州立大学JSAへのDMなど数件で、すべて返信なし
- ロコタビでは応募4名が来たが、手数料と事前決済必須の条件が合わず全員辞退。募集は停止済み
- 欧州は反応あり（ドイツ：J-Connect経由で条件相談中、英国：MixB UK経由で応募あり）

### 0-2. 反応ゼロの原因の見立て
- 打診件数の不足が主因ではない。**届け先が、大学の日本人学生団体の公式窓口に偏っていた**ことが大きい。学生団体は大学とつながっていて、この種の有償の募集を表立って回せる立場にない。残りの連絡先も、団体の公式窓口である限り同じ結果になる見込み
- 対象を日本人に限定したつもりはなかった（オーナー）。ただ、実際に声をかけた先がすべて日本語の窓口だったため、結果として日本人にしか届いていなかった
- → **個人に直接届き、直接やり取りでき、手数料がかからない場所**に変える（2章）

### 0-3. オーナーが却下・修正したこと（理由つき）
| Claudeの提案 | オーナーの判断 | 理由 |
|---|---|---|
| 募集文に「米国で就労資格をお持ちの方」と明記する | **却下** | 応募できる人をこちらから狭めるだけ。反応ゼロの今は、まず広く届くことを優先する |
| ロコタビで応募してきた人に紹介を頼む | **却下** | ロコタビは手数料がかかり、直接取引ができず、連絡がスムーズにならない |
| 報酬を1箱12〜15ドルで出す | **却下**（Claudeが勝手に報酬を上げていた） | オーナーの利益が最優先。ドルで書くなら、元の1,500円をそのまま換算すべき |
| 1箱15ドルの場合のビジネスモデル（まとめ発送、2点目以降の割安料金、190ドル以上の高額品に絞る、日本へ直送できる店は直送） | 参考として聞いたうえで、**1箱10ドルに決定** | 10ドルは1ドル158円で約1,580円。元の1,500円とほぼ同じで、モデルを変えずに済む |

### 0-4. 見せ方が決まった経緯
- **内職として出す**（オーナー）
- オーナーの実体験：以前、自分1人で発送をしていたとき、1日24箱ほどあった。梱包は1時間に20箱でも余裕
- → 1箱3〜5分なら、10ドルは**時給換算で100ドル以上**。1箱の単価だと安く見えるが、時給で見ればかなり割のいい内職。これを前面に出す
- 「いい時だけを前面に出してよいか」→ 時給は作業1時間あたりの効率なので、件数が少ない月でも変わらず、うそにはならない。変わるのは月の件数。件数の波は、相手が引き受けると決める前（顔合わせ）に、最低保証とセットで伝える。始めてから「思っていたより少ない」と辞められると、募集のやり直しがいちばん高くつくため
- 最低保証（最初の3か月、月50ドル）と、件数の見込みを月額で示す案は、オーナーが採用
- **募集の段階で、なにからなにまで公開しない**（オーナー）。募集文は仕事の中身・報酬・地域・連絡先だけにし、詳細は採用が決まってから伝える（3章・3-2）

### 0-5. 言葉の問題
- オーナーは英語が苦手。仕事のやり取りで話す必要はないが、初めましての顔合わせはカメラ越しに話す必要がある（相手が日本人なら迷わずしている）
- → 普段の連絡は文字（メール・チャット）にし、文章は魔王ちゃんが英訳する
- → 顔合わせはGoogle Meetの同時通訳を使う。オーナーがGoogle AI Proに入っていれば、1対1の通話で、オーナーは日本語のまま話せる（相手は無料のままでよい）
- → 英語版の募集にも「日本語話者歓迎」と入れ、日本語ができる人を優先的に拾う

### 0-6. 欧州との関係（Claudeの意見、決定事項ではない）
- 米国は最優先のまま、募集の場所と見せ方を変えて進める
- 欧州は先に進めてよい。魔王ちゃんが台帳に入れた収集済みの商品2,772点はすべてBSTN（ドイツ）で、ドイツのパートナーとそのまま組み合わせられる
- お金の面の注意：ドイツ国内の住所に届けると、ふつうは付加価値税（19%）込みで買うことになる。日本へ直接発送してくれる店の商品は直送にし、パートナーには日本へ発送しない店の商品だけを頼むと、原価が下がる（米国も同じ考え方）

### 0-7. 予備の手段
個人が決まるまでのつなぎとして、オレゴンの発送代行業者（消費税のかからない倉庫を持つ業者や、個別発送を受ける小さな業者）に見積もりを取っておく案もある。必要になれば検討する。

## 3. 募集文（出すのは最小限）

募集の段階では、「何をする仕事か」「いくらか」「どこか」「連絡先」だけを出す。
仕事の細かい流れ・件数の見込み・最低保証・支払い条件は、**3-2の「採用が決まってから説明すること」**に分ける。

### 日本語版（ライトハウス・Facebookグループ）

> **【ポートランド周辺】時給換算100ドル以上｜自宅でできる荷物の発送の内職**
>
> ご自宅に届く荷物を確認して、梱包して発送するお仕事です。
> 1箱10ドル。慣れれば1箱5分ほどです。
> 空いた時間に、自分のペースでできます。
>
> 興味のある方は、お住まいのエリアと一言を [連絡先] までどうぞ。

### 3-2. 採用が決まってから説明すること（顔合わせ・条件メールで伝える）

- 仕事の詳しい流れ（開封 → 写真での報告 → 梱包 → こちらが用意するラベル → 集荷）
- 返品の対応と、追跡番号の報告
- 件数の見込み（今後は月20〜30件）と、件数には月ごとの波があること
- 最初の3か月は、件数が少ない月も最低50ドルを保証すること
- 支払い（月末締め、毎月払い、受け取り方法）
- 商品代金の立て替えはないこと
- 保管は基本不要であること
- 連絡は基本的に文字（メール・チャット）で行うこと
- 作業手順書（5章）を渡すこと
- 最初の1箱はテストとして、作業を記録してもらうこと

件数の波と最低保証は、相手が引き受けると決める前の**顔合わせの時点**で伝える。始めてから「思っていたより少ない」と辞められるのを防ぐため。

## 4. 応募から開始までの流れ

1. **応募の受付**（魔王ちゃん）：返信はその日のうちに。英語の応募には魔王ちゃんが英語で返す
2. **書面で確認**：住所のエリア（州・市）、平日の在宅時間、写真を撮れるスマホがあるか、支払いの受け取り方法（PayPal・Wiseなど）
3. **顔合わせ（10〜15分、カメラあり）**：Google Meetで行う。オーナーがGoogle AI Proに入っていれば、1対1の通話で同時通訳が使え、オーナーは日本語のまま話せる（相手は無料のままでよい）。本番の前に一度試しておく
4. **テスト1箱**：最初の1件は、作業を動画か写真で記録してもらい、梱包の仕方を確認する
5. **開始**：条件を書面（メール）で送り、相手から了承の返信をもらって開始

### 顔合わせの台本（オーナー用、日本語で話す）

1. あいさつと自己紹介（日本でスニーカー・アパレルを販売していること）
2. 仕事の流れ（受け取り → 写真 → 梱包 → ラベル → 集荷）
3. 報酬と条件（3-2の内容：1箱10ドル、毎月払い、件数の見込みと波、最初の3か月は最低50ドル）
4. 連絡は基本的にメール・チャットの文字で行うこと
5. テストの1箱から始めること、次の連絡の予定
6. 相手からの質問（答えにくいものは「あとで文字で返す」でよい）

細かい条件は通話で決めず、通話のあとに文字で送る。

## 5. 作業手順書（パートナーに渡すもの・魔王ちゃんが作成）

写真つきで1枚にまとめる。日本語・英語の両方。

- 開封のしかた（箱・付属品・タグを捨てない）
- 写真の撮り方（外箱、商品の全体、サイズ表記、気になる傷）
- 梱包のしかた（緩衝材、箱の選び方）
- ラベルの貼り方と集荷の申し込み方
- 追跡番号の報告方法
- 返品が来たときの対応

## 6. 件数が増えたときの見直し

- オーナーの実績では、1日24箱でも作業は1〜2時間。内職の範囲で回る
- 為替が大きく動いたら、1箱10ドルを見直す（半年ごとが目安）
- 月100箱を超えるあたりで、パートナーの2人目、または発送代行業者への移行を検討する
