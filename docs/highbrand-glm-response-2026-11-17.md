# GLMの審議案：ハイブランド取り扱いに関する基本方針

## 結論
ハイブランドは**「条件付きで扱う」**べきと判断します。オーナーの選定基準である「日本で買えないもの」を満たす領域であり、利益率向上の機会です。ただし、在庫・資金・真贋リスクが高いため、厳格な事前チェックと限定運用を条件とします。

## 各項目のGLM案

### 1. ハイブランドを取り扱うかどうか
**条件付きで扱う。**
理由：ストリートブランド中心の現状を維持しつつ、収益性とブランド価値を向上させるためハイブランドを追加する。ただし、商標・輸入規制・真贋リスクをクリアした対象のみに限定する。

### 2. 対象にするブランドの範囲と、その線引きの基準
- **範囲**: 本国（欧州・米国）で正規店から入手可能で、日本国内正規店・公式ECで品切れや未発売のアイテムを扱うブランド。
- **線引きの基準**:
  1. 商標権者による並行輸入差止申立てが確認されているブランドは除外（USコンバースと同様の基準）。
  2. BUYMAの規約で出品禁止・制限されているブランドは除外。
  3. 正規ルート（直営店・公認正規取扱店）からの仕入れが確保できるブランドのみ対象。

### 3. 仕入先の条件と真贋確認の方法
- **仕入先条件**: 正規店・正規取扱店のみ。並行店や個人転売屋は不可。ドイツ在住パートナー経由の実店舗買付・直送、または米国パートナー経由の正規店購入に限定する。
- **真贋確認の方法**:
  - 仕入れ時のレシート・納品書・タグ・専用箱・ギャランティカードの画像を必ず保管。
  - BUYMA指定の鑑定サービスの利用を必須とする。
  - GLMが商品データベースに「証跡画像」フィールドを必須項目として設け、欠落時はHOLD状態でインポート不可にする。

### 4. 商標・輸入規制・BUYMA規約の確認方法
- **確認方法**: 
  - 特許庁の商標検索（J-PlatPat）、税関の輸入差止概要措置公示情報を確認。
  - BUYMAの出品ガイドライン・禁止商品リストを都度確認。
- **システム化**: GLMが対象ブランドリストを管理し、商標リスクフラグをPythonスクレイピングのデータベースに統合する。出品前の自動・手動ゲートを設け、リスクフラグが立っている場合はオーナーへ警告を出す仕組みを構築する。

### 5. 価格帯・資金・返品リスクへの対処
- **価格帯・資金繰り**: 初期投資を抑えるため、1商品あたりの仕入れ上限額（例：20万円以内等、オーナー決定）を設ける。パートナーからの買付依頼時はデポジット（前受金）または即時決済を条件とし、キャッシュフローの停滞を防ぐ。
- **返品リスク**: BUYMAの真贋鑑定・返品ルールを前提とする。自サイト（AFTER HOURS CLUB）では「ハイブランドの返品・交換不可」を利用規約に明記する。配送中の紛失・破損リスクに備え、高額商品の輸送保険加入を必須とする。

### 6. 最初に試す最小の形（MVP）
- **商品数**: 1〜3点のみ。
- **対象**: ドイツパートナー経由で確実に正規店から調達でき、日本国内で希少性の高い1ブランド（例：特定のハイエンドストリート、または定番ハイブランドの未入荷アイテム）。
- **手順**:
  1. 仕入れ前チェック（商標・規約・BUYMA制限の確認）
  2. パートナー経由で仕入れ・証跡画像取得
  3. BUYMA指定の鑑定
  4. BUYMAへ出品（自サイトは保留または同時テスト出品）
  5. 結果検証（利益率・返品有無・作業工数）後、展開可否を決定。
