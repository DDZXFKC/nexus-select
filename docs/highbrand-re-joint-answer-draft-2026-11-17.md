関係者: GPT, Claude, GLM

## 1. なぜ前提の欠落（仕入れルート・買い付け方法が未確立）に誰も気づかなかったのか
3者（GPT, Claude, GLM）の共通の原因として以下の3点を挙げる。

1. **問いの形のまま答えた**: 開始文書の問いが「扱うか・対象範囲・仕入先条件・規制・資金・MVP」であったため、各項目を埋めることに集中し、「その答えは実行できるか」を確かめる項目がなかった。正規仕入先の証拠を出品条件に入れたが、その正規仕入先に実際に手が届くかを一度も確かめなかった。
2. **スニーカーの仕入れ網を流用できると思い込んだ**: Foot Locker・BSTN等の実績があるため、「どこかで買える」と無意識に置いていた。実際はハイブランドの仕入れ実績はゼロ、米国パートナーは店舗買い付けをしない、ありさんは未稼働であった。
3. **注文1件の流れを最後までなぞらなかった**: 誰が・どの店で・何で払って・税金はどうなり・どう日本に届き・関税は誰が払うかを1件だけでも書けば、空欄にすぐ気づいた。

**再発防止（3者共通ルール）**:
事業判断の審議では、**必ず「注文1件の流れ」を書き、各段に「確認済み／未確認」を付ける。** 未確認が1つでも残る案は「実行可能」と書かない。

## 2. 前回の答えが今後のビジネスに与える影響
前回の審議で出た「条件付きで取り扱う」「1点15万円・同時1注文」といった結論は、仕入れ可能性を証明しておらず、以下の良い面と悪い面がある。

**良い面（残して使えるもの）**:
- 「正規店・新品のみ」「二次流通のプレミア品は扱わない」「商品ごとに差止・規約を確認」「証跡の保存」「無在庫」という安全条件は、どの仕入れルートになっても使える。出品後に問題が出るのを防ぐ基盤として残す。

**悪い面（具体的な影響）**:
- **キャンセルと評価低下リスク**: そのまま実行していたら、BUYMAに出品 → 注文が入る → 買える人・店が決まっていない → キャンセルとなる。BUYMA再開の立ち上げ期にキャンセルが出ると、ショップ評価に直接響き、ストリート商品の売上まで巻き込む。
- **根拠のない上限**: 1点の原価もルートも未計算のまま「15万円」という数字だけ置いたため、資金繰りの実態と合わない恐れがあった。
- **機会損失**: 審議の時間を使った分、収集Pythonやクーポン部品など、売上に近い作業の時間を削った。

## 3. 利益を出すまでのロードマップ（前提づくりから）
対象ブランド：プラダ、グッチ、コーチ、エルメス（並列調査）
※ルート定義：A=欧州実店舗、B=欧州正規オンライン、C=米国オンライン、D=BtoB卸売

### Phase -1：ルートと商品の存在証明（支出0円）
パートナーの稼働や資金を待たず、3者が公開情報と許可済みの手段で調査する。

**やること**:
1. **仕入先調査と需要照合**: 各ブランド10〜30候補を探索（購入・出品ノルマではない）。国内からの逆引き（日本で不足している商品を探す）と、アウトレット/ありさんからの順引き（現地で買えそうな商品を探す）の両方を行う。
2. **店別条件確認**: 各ルートの候補店について、商業購入の可否、配送、請求・カードの通る可能性、正規取扱の証拠、返品条件、輸出/税、在庫確認の手段、画像利用条件を、根拠URL・日時付きで確認する。
3. **共通採算式での利益判定**: 以下の「共通採算式」を用いて、実原価と利益を算出する。

**共通採算式（修正案）**:
- **売れる価格P**: 同一品番/色/仕様/状態/サイズの国内公式・BUYMA実勢価格（出品と成約を区別）。※アウトレット品の場合は、現行品の日本定価ではなく、同じ型の型落ち・アウトレット品の国内実勢価格から取る。
- **現金立替原価C**＝商品請求額×実決済為替＋現地税（請求額含有なら再加算しない）＋現地送料/移動＋買付/発送報酬＋国際送料/保険＋商業輸入の関税＋輸入消費税＋通関費＋国内送料/梱包＋その他実費。
- **取引利益**＝P − 実際の成約手数料 − 振込手数料按分 − C − 返品等リスク引当/追加費用。
- ※0.745の現行式は内訳が確定するまで流用しない。目標利益Tなら許容原価＝P−手数料−T−リスク引当。

**数字の例（€500税込商品、EUR/JPY=175、為替費2%、関税10%、消費税10%、売価140,000円、BUYMA手数料7.7%=10,780円、振込385円で仮定）**:
- **ルートA（欧州実店舗・VAT込み）**: 商品決済89,250円 ＋送料保険7,000 ＋関税9,450 ＋輸入消費税10,395 ＋報酬3,000 ＋国内送料1,000 ＋梱包500 ＋通関費1,000 ＋交通費2,000 ＝ 総原価123,595円。**取引利益 5,240円**。
- **ルートB（欧州オンライン・VAT抜き）**: 商品決済75,000円 ＋送料保険3,000 ＋関税7,653 ＋輸入消費税8,418 ＋国内送料1,000 ＋梱包500 ＋通関費1,000 ＝ 総原価96,571円。**取引利益 32,264円**。
- **ルートA（アウトレット€350税込の場合）**: 商品決済62,475円 ＋送料保険7,000 ＋関税6,825 ＋輸入消費税7,508 ＋報酬3,000 ＋国内送料1,000 ＋梱包500 ＋通関費1,000 ＋交通費2,000 ＝ 総原価91,308円。**取引利益 37,527円**。（※売価Pは型落ち品の実勢価格から取る前提）

**Phase -1の成果物**:
仕入ルート台帳、SKU比較表（品番・色・サイズ・商品URL・国内状況/需要・競合価格・現地税込/税抜価格・実費内訳・利益・資金拘束・証拠・未確認理由）、注文1件のフロー。

**次へ進む条件**:
1ルート1SKUでも全条件（需要・利益・物流・資金・正規証拠）が成立したら次へ進む。初回調査で0件なら該当ブランド×ルートは休止し、既存ストリート事業を優先。5候補は拡大判断の参考目標に過ぎない。

### Phase 0：出品準備（支出0円）
- **やること**: Phase -1で条件を満たした商品を、合意済みの出品前ゲート（差止・規約・正規仕入先の証拠・画像利用権）に通す。関税を購入者負担にするか、オーナー負担（価格に込める）かを確定する。輸入規制、返品・保険・BUYMA条件・資金上限を確定する。
- **注意**: 購入前の在庫・決済可能性は許可された方法で確認し、実決済は行わない。買付/販売に必要な業務合意・配送条件の確証がない商品はHOLD。
- **方針**: BUYMA先行。専用サイトは優先順位最下位。
- **次へ進む条件**: BUYMAに無在庫で出品できる状態（3〜5点）が整うこと。

### Phase 1：1件の実取引（オーナー承認後）
- **やること**: オーナー承認を得た候補のみ無在庫で出品。注文が入ったら、在庫・価格・税・規約を再確認し、1点だけ買付・検品・発送を行う。
- **資金の目安**: 1件あたり約8〜10万円が、買付からBUYMA入金まで約3〜4週間拘束される。1件目は全費用を自己資金で払える1注文のみとする。前受金でBUYMA資金を使えると仮定しない。
- **測定するもの**: 実原価、届くまでの日数、関税の扱い、作業時間、購入者の反応、実際の利益・資金拘束日数・トラブル。

### Phase 2：月3〜5件での運用と拡大判定（2027年1月〜）
- **やること**: 利益が出た1件を基に、同ルートで再現性を検証。取引を月3〜5件程度に増やす（目標例であり保証ではない）。
- **拡大判定**: 利益額・資金拘束・工数が既存ストリート事業より有利か比較し、初めて拡大判断を行う。高固定費のBtoBや専用サイトは必要になってから検討する。初期調査で成果がなければ既存事業を止めない。

## 4. ドイツ店頭在庫への対応（確認してから売る）
ドイツの店頭在庫は予想できないため、「予想しようとせず、確認してから売る」ことで外れたときの損（キャンセルによる評価低下）を小さくする。

1. **システムによる警告（GLM実装）**: 商品DBに「店頭在庫確認日」「有効期限（例：確認から14日）」「担当者名」フィールドを追加する。期限を過ぎた商品は自動的に「要再確認」の警告を出す。※14日は在庫の保証ではなく、警告トリガーに過ぎない。
2. **業務フロー（Muse・ありさん実行）**:
   - **出品時**: BUYMAの出品説明文に「在庫確認のため、発送まで〇日いただきます」と明記し、キャンセルリスクを下げる。
   - **受注時**: 注文が入ったら、ありさんが担当者（クライアントアドバイザー）に在庫確認・取り置きを依頼。確認できてから事前送金・買付に進む（確認できない場合はキャンセル）。
   - **確認のタイミング**: 毎日全候補の在庫確認をありさんに課す設計にはしない。「注文が入ったとき」と「店を回る中で自然に分かったとき」に限る。
3. **データの蓄積**: 在庫確認のたびに「商品・店・日付・あった/なかった・サイズ」をDBに記録し、数週間後にはどの商品が安定して置いてあるかをデータで少しずつ予想できるようにする。

## 5. オーナーに判断してもらう事項
以下の項目は、3者（GPT, Claude, GLM）が決定できる範囲を超えるため、オーナーの最終判断が必要です。

1. **ハイブランドに回せる資金の上限額**: 既存事業の最低資金と返金予備費を除いた、自由に使える額。
2. **ルートA（欧州実店舗）の発送先と関税負担**:
   - A-1：ありさんが現地で検品 → 購入者へ直送（国内送料なし、輸入者・税負担の決め方が要る）
   - A-2：ありさん → 自宅兼事務所経由 → 再検品 → 国内発送（オーナーが実物確認、関税・消費税・国内送料はオーナー負担）
3. **ありさんのハンティング報酬・交通費**: 現行報酬（買付2,000円＋発送1,000円）は維持するが、候補商品の提案（ハンティング）や遠距離移動の交通費の扱いについて、ありさんと相談のうえ決定する（3者は金額を決めない）。また、原価・利益の列をありさんに見せるかどうか（3者の既定案は「見せない」）。
4. **対象ブランド・SKUの最終選定と出品承認**: Phase -1の調査結果を基に、実際にBUYMAへ出品してよいかを最終決定する。
