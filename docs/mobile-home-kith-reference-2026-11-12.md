# NEXUS SELECT — モバイルホーム改修提案
2026-11-12 / ChatGPT → Muse・Grok

## ユーザー要望
Kithのスマホ版ホームのような、大きな動画が流れるトップページを作りたい。

## 提案仕様（レビュー対象）
- 参考: https://kith.com/ 。現行モバイル実機の動きは未検証。まずiPhone Safari相当で実測し、構成・動画比率・ヘッダー・スクロール・CTAを確認する。
- 白いヘッダー、中央NEXUS SELECT、左メニュー、右検索・バッグ。
- ファーストビューに画面幅いっぱいの縦長キャンペーン動画。10〜15秒程度を初期案とし、autoplay muted loop playsinline、音声なし。動画の下にコレクション名とSHOP NOW。
- NEW ARRIVALSの正方形白背景商品2列、MEN'S / WOMEN'S / KIDS、BRANDSへの導線、キャンペーン・ルックブックを組み合わせる。
- 動画は自社制作または商用利用許諾済み素材のみ。Kithのロゴ・映像・写真・コードは無断転載しない。
- MP4/WebM、poster、適切な圧縮、画面外停止、低速回線・自動再生不可・prefers-reduced-motion時の静止画代替、停止操作を用意。LCP/CLSと通信量を実測し、既存サイトより著しく遅くしない。
- WordPress/WooCommerceの既存テーマ内で実装。有料プラグイン購入なし。PC確定デザイン、商品詳細、カート、決済、商品データは維持。商品詳細の変更は別途ユーザー承認必須。

## 3者レビューと実行
Muse: 現行テーマを確認し、モバイルホーム限定の差分・実装方法・実機検証結果を共有。
Grok: Kith現行モバイルの構成・動画演出を調査し、改善案とパフォーマンス対策を共有。
ChatGPT: 両者の結果を比較し、仕様・受入条件を確定する。
各者はこのブランチにレビューを保存し、ユーザーを伝言役にしない。3者合意後にまとめて報告。既存の公開条件を変更しない。

## 受入条件
iPhone Safari/Android Chromeで自動再生または適切な代替表示、横はみ出しなし、文字重なりなし、CTA・ナビ・商品リンク正常、動画停止可能、PC版回帰なし。動画素材未確保の場合は公開用完成とみなさない。
