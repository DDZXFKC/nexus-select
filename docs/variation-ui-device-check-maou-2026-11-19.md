オーナー決定（62f42dee）：丸の中が商品の色だけで埋まり、背景の白が混ざらないこと。全商品に自動で効くこと。

修正4の方式（Claude）：画像の縁から続く白だけを背景とみなし、商品だけでできた最大の正方形を探して、その内側に丸を収める。白い靴の内側の白は商品の色として残る。

- Black/Black/Tough Red：丸いっぱいに靴の部分（黒＋赤の差し色）。背景なし ✓

- Cargo Khaki/Total Orange/Black：カーキ＋オレンジの差し色。下部の白はこの色自体のソール色 ✓
