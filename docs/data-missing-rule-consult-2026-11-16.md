## 決めたいこと
収集・投入の工程で、必須とされる情報（サイズ換算・素材・価格・在庫など）が元データや公式ソースから取れなかった場合の一般ルール。論点：

1. 欠落したまま投入してよいか、投入前に止めるべきか（止めるなら、どの項目が・何件欠けたら止めるか）
2. 欠落の検出方法（投入前チェックに組み込むべき項目と方法）
3. 欠落した情報の埋め方（追加調査／実物到着時の検品実測／推測で埋めてよい範囲と、絶対に推測しない線引き）
4. 欠落の報告方法（投入完了報告への含め方）
5. 公開可否（欠落のある商品は公開を遅らせるか、公開してよいか）
