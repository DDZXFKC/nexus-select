## 指摘（オーナー判断が必要）
1. **FL・MERGED などの正方形 PNG 約 420 件は、背景が白ではなく透明。**
   - オーナー決定は「PNG は白い正方形に置くだけ」。これらは白の下地を入れずに、透明のまま正方形にしてある。
   - 商品ページの背景は白なので、見た目は白く見える。
   - ただし、背景が白でない場所に出したときは白にならない。例：一覧カードの灰色、SNS、BUYMA などの外部への出力。
   - 白い下地を入れるかどうか、オーナーの判断が必要。入れる場合は、画像の置き換えを伴う。
2. **FL の正方形でない 4 件**（6374・6546・6640・9834）は、まだ直していない。
   - 元の画像が JPEG/WebP で、PNG ではない。FL の SKU は Foot Locker の品番で、メーカーの型番ではない。
   - そのため、オーナー決定の範囲（同じ型番なら Stadium Goods の PNG）では自動で置き換えられない。
3. **SP の HOLD 37 件**はグレーの JPEG のまま。内訳は docs/image-apply-plan-sp158-claude-2026-11-22.md。
4. **画像なし 37 件**（CV 25・NK 8・MERGED 4、すべて下書き）は未着手。
