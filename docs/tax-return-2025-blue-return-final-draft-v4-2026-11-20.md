## 1. 追加のオーナー決定と生命保険料
1. **所得区分**：「事業所得で進める」（2026-11-20）を本線の申告方針として採用。DJ収入は青色申告決算書（一般用）の事業収入として整理。税務上の事業所得該当性が客観資料で裏付けられるかは提出前に検証する（本人の申告方針だけで法的区分が確定するわけではない）。
2. **青色申告**：以前の申告は青色のみとのオーナー確認があり、過去の承認取得済みを作成前提とする。期限後申告では55万・65万円控除の期限内提出要件を満たさない。事業所得があり青色の帳簿保存等の要件を満たす場合の**最高10万円控除**を本線に適用（2025年の承認継続・記帳・決算書内容は提出前確認）。
3. **日本生命・一般生命保険料（新制度）**：2025年11月1日加入、月7,297円×2025年11月・12月の2か月＝**2025年支払保険料14,594円**と本人確認。新契約の一般生命保険料で年間支払額20,000円以下の場合、所得税の控除額は支払額全額となり**14,594円控除**。**2026年分（令和8年分）証明書の87,564円は2025年分に転用しない**。令和7年分の控除証明書画像・実際の払込日を正式申告前に最終確認し、給与年末調整で同じ控除がすでに含まれていれば二重反映しない。
4. **Amazon経費**：購入67件204,184円−Amazon由来の返金・取消6件27,046円＝**純177,138円**。「経費計上する」本人決定により本線に採用。ただし**税務上の必要経費性（購入品別の事業用途・私用割合・資産計上/減価償却）を証明するまで税務上確定した必要経費ではない**。JR東日本・ヨドバシの別返金30,354円はAmazonから差し引かない。
