(b) 統合文の草案（全文）
AFTER HOURS CLUB サイト位置づけに関する3者統一意見（草案 v1／Claude起草）
前提（オーナー決定） 自サイトの想定客は新規のお客様。在庫確認ボタンは全商品・全カラー・全サイズの商品ページに設置する。
1. 店の位置づけと言葉
「買い付け代行」は店の看板として使わない。事務的・業者的に響き、ブランドの芯（ファッションは楽しむもの、個性そのもの）と合わないため。
店の位置づけ：海外買い付けのセレクトショップ。
売り方の表示：海外お取り寄せ（「ご注文後に海外ショップから買い付け、検品してお届けします」）。
法的な表記では、当店が価格を決めて売る通信販売の売り手として正確に書く。「代行」「代理購入」とは書かない。名乗り方で売り手の責任は軽くならない。
2. 無在庫販売は自サイトで実現できるか、堂々と告知してよいか
実現できる。注文後に買い付ける販売方式そのものは違法ではなく、隠す必要もない。
法的に問題になるのは、無在庫であることではなく、調達できない商品を、調達できるように見せること（景品表示法のおとり広告）。売り切れ商品の取り下げと、在庫確認の仕組みで防ぐ。
特定商取引法：販売者情報・支払時期・引渡時期・返品条件を、特商法の表示ページと注文確定直前の画面の両方に表示する。前払いを受ける場合は承諾の通知を行う。返品特約を必ず書く（書かないと、受け取りから8日間は返品できてしまう）。不良品・誤配送・未着の責任は免除しない。
公開前に、特商法の表示と最終確認画面の文面を、通信販売に詳しい専門家に確認してもらう。
3. 購入の流れ 商品・カラー・サイズを選ぶ → 在庫確認ボタン（会員登録は不要、即時に自動返信） → 在庫・価格を確認（自動確認を優先し、できない場合は手動確認） → 購入できる旨の案内（確定価格・お届け予定・案内の有効期限） → 注文・カード決済（仮押さえ方式を第一候補として検証） → 海外で買い付け → 検品 → 配送（注文追跡で進捗を確認）→ お届け
商品ページには税込の販売価格を確定値として表示する。価格が変わる場合は注文前に提示して同意を得る。成立した注文に追加請求はしない。
在庫確認の結果は、取り置きが成立していない限り「確保済み」とは表示しない。決済の直前と買い付けの直前に再確認する。
買い付けできなかった場合は、全額返金（または仮押さえの取り消し）。
「お金は一切動きません」のような表現は使わない（利用枠の確保や、デビットカードの即時引き落としがあるため）。
4. 決済の確定時期（検証事項）
日本のStripeアカウントでは、日本円建てのVisa・Mastercard・JCB・Diners・Discoverは最大30日間の仮押さえが可能。American Expressと日本円以外は7日間。海外発行カードには、さらに短い規定がある。
「買い付け完了時」「発送時」「到着後」の3つの方式から、次の確認を経て決める：①当店の販売方式がStripeの審査で認められるか、②WooCommerceで30日の仮押さえを実際に維持できるか、③到着後の確定が規約上認められるか、④期限切れ・遅配・紛失時の処理、⑤注文追跡との連携（注文の状態を変えると売上が確定する仕様に注意）。
検証が終わるまでの暫定は「買い付け完了時に確定」。到着後に確定する方式は、立替資金（試算で平均約40万円＋返金の予備費）が必要になるため、資金面を含めてオーナーが判断する。
5. 在庫確認の運用
目標：自動返信は即時、自動確認は数分以内、営業時間内の手動確認はできるだけ早く、海外実店舗への確認は24時間以内（社内目標）。
お客様に約束する返信時間は、運用テストで実測してから掲示する。受付時間をボタンの近くに書く。
自動確認は、許可された方法で情報を取得できる店に限る。古い在庫情報だけで購入可能と判定しない。確認結果が分からない場合は「購入不可・確認継続」とする。
在庫がない場合も必ず返信する。
6. 購入者保護
自サイト独自の安心材料：買えなかった場合の全額返金、検品、注文追跡による進捗の見える化、配送トラブル時の対応。
配送中の紛失・破損は、お客様に配送会社と交渉させず、当店が窓口となって返金・再手配する。配送保険で足りない分は当店の資金で備える。
実際に提供できる体制が整ったものだけを、サイトで約束する。
7. 広告
堂々と告知してよい。ただし、広告を始めるのは調達・配送・返金の体制が整ってから。
全商品が在庫確認方式の場合、Googleショッピング広告は、購入ボタンの条件を満たせず使えない可能性が高い（条件の確認が必要）。集客の主力は、Google検索広告、Instagramの通常広告、サイト・ブランドの紹介広告とする。
「BUYMAより安い」などの比較表示は、根拠が崩れると有利誤認になるおそれがあるため慎重に扱う。
8. 効果の測定 「商品ページ閲覧 → 在庫確認依頼 → 購入可能の回答 → 決済 → お届け完了」の各段階の数と、返信時間・確認作業時間・買い付けできなかった率・広告費・取引ごとの利益を記録する。成約率への影響は推測で断定せず、実測で改善する。
9. 進める順番 ①決済会社の審査・仮押さえ期限・資金条件の確認 → ②在庫確認ボタンから注文までの最小構成の実装 → ③商品収集Pythonとの在庫確認の連携 → ④注文追跡との連携 → ⑤特商法の表示・購入者保護・配送補償の整備 → ⑥実際の取引と異常時の対応の検証 → ⑦専門家確認のうえ、本番公開・広告開始をオーナーが判断。
