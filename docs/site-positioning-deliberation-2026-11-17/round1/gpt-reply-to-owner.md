## 1. Stripeの30日間オーソリとは？

Stripe公式の期限は以下のとおり。

| 決済条件 | オーソリ期限 |
|---|---|
| 日本国内発行カード・日本円決済 | 30日間 |
| 外貨建ての通常決済 | 7日間 |
| 外貨建ての継続課金等 | 5日間 |

海外発行カードで日本円決済する場合もStripe上は30日間だが、Visaの規定では通常のオンライン購入に10日間という短い期限が適用されるため、別途注意が必要。

公式資料：日本におけるVisa Processing Integrity Program Fee（support.stripe.com）

つまり、日本のお客様を対象に日本円で販売するAFTER HOURS CLUBにとって、非常に相性の良い仕組みである可能性がある。

## 2. 具体的にどういう仕組みなのか？

例えば、AFTER HOURS CLUBで30,000円のスニーカーが売れた場合。

注文金額 ¥30,000

- 1日目：お客様がカードで注文
  30,000円の利用枠を確保。売上はまだ確定しない。
- 2日目：海外ショップで買い付け
  AFTER HOURS CLUBが商品代金を立て替える。
- 7日目：現地パートナーへ到着
  商品を検品し、日本へ発送。
- 15日目：お客様へ商品到着
  配送完了を確認。
- 16日目：売上確定（キャプチャー）
  ここでカード売上を確定する。

30日間のオーソリが実際に適用される場合の運用例。配送日数は仮定。

この仕組みを使えば、商品が到着してから売上を確定するという、BUYMAに近い取引を実現できる可能性がある。

ただし、Stripeが第三者として商品到着や取引の安全を保証するわけではない。売上確定の操作と購入者保護は我々の責任となる。

また、クレジットカードの利用枠は注文時点で拘束される。デビットカードでは注文時点で口座から引き落とされる場合がある。

## 3. 買い付けできなかった場合は？

これも大きなメリット。

|  | 通常の即時決済 | オーソリ方式 |
|---|---|---|
| 注文時 | ¥30,000 売上確定済み | ¥30,000 仮売上のみ |
| 買付不能 | 返金処理 | 仮売上の取消 |

売上を確定する前に買付不能と判明すれば、通常の返金ではなく、カードのオーソリを取り消すことで対応できる。利用枠の回復時期はカード発行会社によって異なる。

## 4. どのカードが30日間に対応しているのか？

Stripeの開発者向け公式資料にも、日本のアカウントにおける30日間オーソリの記載がある。

（資料カード表示：最大30日／通常7日）

日本のStripeアカウントで日本円決済を行う場合の対応。American Expressは30日間の対象外。海外発行カードについては別途カード会社の規定にも注意が必要。

公式資料：Stripe — 30-day authorization windows in Japan（docs.stripe.com）

Visa、Mastercard、JCBが対応していることは大きい。

## 5. WooCommerceで使えるのか？

WooCommerce公式のStripeプラグインには、オーソリと売上確定を分ける機能が標準搭載されている。

設定場所は以下のとおり。
WooCommerce → 設定 → 決済 → Stripe → 設定 → Payments & transactions
「Issue an authorization on checkout, and capture later」を有効にする。

これにより、注文時に売上確定せず、後から管理画面で確定できる。

ただし、注意すべき点が2つある。

- プラグインの設定画面には7日間という説明があるため、日本向け30日間オーソリが正常に維持されるか実機検証が必要。
- 注文ステータスを「処理中」「完了」に変更すると売上が確定する仕様がある。現在開発中の注文追跡プラグインとの連携に注意が必要。

Stripe APIには capture_before という、取引ごとの売上確定期限を取得できる項目がある。この期限を自作プラグインで管理すれば、期限切れの事故を防ぐ仕組みも作れる。
