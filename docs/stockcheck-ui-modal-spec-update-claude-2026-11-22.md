## 変更点（ahc-stock-check-ui.js）
- **カート追加が成功したら、ポップアップを閉じて商品ページに留まる。** カートページへは移らない。
  - ミニカートは `wc_fragment_refresh` で更新する。
  - ボタンの下に「カートに追加しました。」と出す。
- **カート追加が失敗したら、ポップアップを開いたままエラーを出す。** 自動の再試行はしない。
- ボタンは「この商品をカートに入れる」。その下に「キャンセル」を置く。
  - キャンセルは、カートに入れずに閉じる。サイズの選択はそのまま残す。
  - 掲載価格のまま・現在価格を案内、のどちらの場合も同じ。
- **サイズ表示**：Woo のサイズに cm が書いてある場合だけ「US 3Y / 23cm」形式で表示する。
  - 例：「US 3Y (23cm)」→「US 3Y / 23cm」。
  - 「US 9」のように cm が無ければそのまま表示し、推測で cm を足さない。
  - 表示用の文字を変えるだけで、元の値・結合・カートに使う値は変えない。
- **買い付け先が読めないとき**：「つながらず確認できなかった」と説明し、時間をおいた再確認をお願いする。
  - 自動の再試行・「確認中」のまま保持、はしない（1 回の確認が終わったら止まる）。

## GPT・オーナーへの確認（監査）
1. 仕様の「自動期限切れは設けない」と、GPT サーバー側の**購入許可の有効期限（300 秒）**が衝突しないか。
   - 衝突する場合：在庫確認から 5 分以上たってから「カートに入れる」を押すと、permit_expired で断られる。
   - 衝突しない場合：仕様の「期限切れなし」は在庫確認の状態の話で、購入許可の期限とは別、という解釈になる。
   - どちらかオーナーの確認が必要。
2. カート追加成功時の応答に `cart_url` は不要になった（`ok` だけ見る）。GPT 側はそのままでも動く。
