## B. 税額と個人情報の確定に必要な確認

- [ ] **B1：本人情報**：戸籍/本人確認書類どおりの氏名・フリガナ、生年月日、連絡先、世帯主との関係、納税地、2025年末/2026年提出時点の住所と住み始めた時期。現住所の表記は**【現住所：依頼文書の確定値を非公開の正式申告書へ転記】**で記載することを依頼文書で確定済み。ただし提出正式様式が求める「現在/当時の住所」区別を誤記しない。GitHubには個人番号/銀行口座をアップロードしない。
- [ ] **B2：2025年の社会保険料総額**：給与天引き（源泉徴収票に記載）と本人直接納付（国民年金・国民健康保険・介護等があればその2025年領収/証明）を**重複しないよう**分ける。
- [ ] **B3：2025年に他の所得があったか**：副業、別雇用先、利息/配当、株式・暗号資産・不動産・譲渡・年金・一時所得等。該当するものは支払者・金額・税の天引き情報と記録。
- [ ] **B4：家族関係・所得控除**：配偶者/扶養親族（年齢/所得/生計）、障害者、ひとり親、医療費、寄附金（ふるさと納税）、地震保険、iDeCo・小規模企業共済、住宅ローン控除、その他。該当なしなら「該当なし」の確認だけでよい。
- [ ] **B5：源泉徴収税額・予定納税・その他の税額控除**：勤務先源泉徴収税額、DJ謝礼の源泉、予定納税納付の有無、年末調整実施の有無。還付の有無を計算するまで、口座情報は収集不要。
- [ ] **B6：事業区分**：DJ音楽制作とアパレルが同一事業の経理か、別活動か。帳簿、規模、継続性、請負関係、過去の申告記載から**事業所得／雑所得**の扱いを検討する。二重計上禁止。
