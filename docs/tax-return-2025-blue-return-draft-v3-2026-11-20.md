> **この文書の「確定」は青色申告方式の採用というオーナー判断を指す。税額や申告書の提出完了を意味しない。** 当該GitHubリポジトリは公開であり、個人の金額情報を公開する可能性がある。現住所全文・源泉徴収票画像・口座番号・マイナンバーなどは載せない。2025年分の正式申告は非公開で作成し、税務署提出前に裏付け資料を確認する。

## 0. 本日決定と制度上の区別
- オーナー：「青色はしたことあるよ」「てか青しかした事ない」。**以前の申告は青色のみ、青色申告承認取得済みとして作業を進め、2025年分の申告書類の構成を「青色申告決算書（一般用）＋所得税確定申告書第一表・第二表」に固定**する。
- 過去の青色実績は本人申告として受領した事実。2019年以降の承認の効力が2025年も継続し、取消や取りやめがないかは提出直前に承認状況・過去の申告控え等と照合する（オーナー回答を再質問する趣旨ではない）。
- **期限後申告**のため、55万円・65万円の控除は法定期限内提出要件を満たせず適用しない。10万円控除は期限内提出要件がなく、**青色申告者で事業所得（ほか不動産所得・山林所得）があり、青色申告制度に基づく帳簿等の要件を満たし、損益通算前の黒字所得を限度とする場合**に最高10万円を適用可能。雑所得・給与所得だけからは控除できない。
- DJ収入の所得区分は**未決**。青色承認とDJの事業所得該当は別の判定。アパレル売上0円は確定だが、アパレル事業の所得・経費・資産はなお未確定。DJが雑所得である場合、他に青色控除の対象となる黒字所得が確認されていないため**この試算では青色特別控除を適用しない**（申告者が青色申告者でなくなるという意味ではない）。
- 国税庁 No.2072 青色申告特別控除 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2072.htm
- 国税庁 令和7年分「青色申告特別控除のあらまし」 https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/046.pdf
- 日本税務研究センター（期限後申告と10万円控除） https://www.jtri.or.jp/counsel/detail.php?id=435

この欄は**青色申告決算書の数字の骨子**であり、正式な帳票に必要な売上先別明細、仕入、期首期末棚卸、減価償却、未収/未払、資産・負債、貸借対照表等を0円と仮定・記入したものではない。税務上の売上計上年・個別支出の必要経費性を確定してから正式帳票へ入力する。

### DJが雑所得と判断される場合
- 上記614,877円のDJ総収入と認容された必要経費は、**確定申告書の雑所得（業務）**側で計算。DJの売上・経費を青色申告決算書の事業損益に二重計上しない。
- 青色申告決算書は2025年のアパレル事業（売上0円、**仕入・経費・資産・損益未確定**）について別途作成する。アパレルの黒字の事業所得などが確認されていなければDJの雑所得に青色申告特別控除は適用できない。青色承認を得ていることだけで一律10万円の控除はしない。
- いずれのケースもアパレル側の真の損益が未確定なので、数値試算は暫定値。

## 4. 決算書作成・申告前の残りの確認（重要度順）
1. DJが事業所得か雑所得か：継続性、独立性、従来の申告方法、帳簿、取引先との業務実態を用いて判断。**青色承認済み＝DJも事業所得という推定は禁止**。
2. 青色申告承認の2025年での有効性（過去の承認書・申告控え/取りやめ・取消通知の有無）。既往の青色申告実績はオーナー確認済みとして再質問しない。
3. 2025年分日本生命控除証明書（支払額・区分）、年末調整済み保険料控除、その他本人直接納付社会保険・各種控除。
4. RANGE事業口座8件の請求・源泉：オーナー指示で344,490円を暫定収入計上するが、源泉税の有無・額をゼロとは確定しない。RANGE個人口座9件の源泉27,056円も支払者資料で最終照合。
5. Amazon67購入−6返金、SERATO17件、サウンドハウス購入の**事業必要性・私用混在・資産計上・領収書**。Amazon全額177,138円を自動的に必要経費としない。
6. 未分類入金100,000円（フエイト／マイルストーン／ベニタニ／ゴウダ ゲンキ）の性質。本人名義口座間移動は売上ではなく、同じ金額の他人名義入金まで自己振替と推定しない。
7. 事業帳簿、棚卸、2025年末の売掛金/未払金、固定資産、青色決算書の損益計算書・貸借対照表の残る欄。アパレル売上0円＝全欄0円ではない。
8. 給与の原票の控除済み項目・複数給与の有無、2025年分の提出履歴、税金の予定納付。KOMOJUの現住所表記は申告書提出時に別途確認。
