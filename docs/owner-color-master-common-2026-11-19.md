# オーナー決定：カラーマスター全ブランド共通（2026-11-19）
原文：「コレはやめよ。全ブランド共通でいいと思う。ユーザーが多数のカラーがあるということを認識できればそれで良い」
対象：70ee0596のブランド別・商品別色マスター設計、および後続検収1d6d0b89/c51beeecの該当箇所を置き換える。
決定：丸窓の目的は色の種類・カラーバリエーションの案内であり、実物の色の厳密な再現ではない。全ブランド共通のカラーマスターとし、正規化色名を一意キーにする。scope_type/scope_keyによるブランド別・商品別の色コード管理は廃止（既存列は移行確認まで保持してよい）。同一色名は共通HEXを一度登録し再利用。既存の近似パレットを積極利用し、微妙な色差の調査を目的にしない。Moss Green等の原文色名は保持し、表示用近似色と基本色系統を区別。商品カラー表の店舗・市場・商品・カラー識別子、色名全文、構成色全件・順序・重複、店舗タグ原文は維持。最大3色・縦等分・原文順・4色以上先頭3色・選択時全文表示は不変。実物色は商品画像で確認。未知語は基本色候補や店タグで合理的に分類し、判定不能は保留。色見本の近似とBUYMA主色分類は別であり、店舗タグの矛盾・公式ID未確認を勝手に確定しない。既存13トークン/9商品を共通キーへ移行し、重複と参照整合を確認してから全件処理。既存商品原本・価格・本番変更なし。Museはシート、Python担当は照合、ClaudeはUI連携をこの方針に変更。オーナー追加判断不要。
