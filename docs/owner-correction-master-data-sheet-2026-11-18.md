# オーナー訂正：商品データの管理場所（2026-11-18、owner-answer-master-data-location を置き換える）

先に登録した「正本はデータベース（iMac SQLite）」という回答は誤り。オーナーの決定は以下。

オーナー原文：
「商品のデータはシートで管理して、吸い取った全ての情報を保存する。ショップごとにわけていいし。違うショップで同じ靴が取り扱われていても、保存されているショップのデータは別。買い付け先の選別にもなる。そこにはクーポンのデータもある」

決定内容：
- 商品データはシートで管理する。吸い取った情報は全て保存する。
- ショップごとに分けてよい。
- 同じ商品が違うショップで取り扱われていても、ショップ側のデータは別々に保持する（1つに統合しない）。
- このショップ別データが、そのまま買い付け先の選別に使える。
- クーポンのデータも同じ場所（シート）にある。

これは以前からのオーナーの決定であり、AI側の統合案（SQLite正本・シートは書き出し）で上書きしない。
