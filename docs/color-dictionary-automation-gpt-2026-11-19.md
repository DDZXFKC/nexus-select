# 色判定の自動化方針：外部色辞書優先
オーナー指示：魔王ちゃんによる商品画像の色判定は無し。ネットの既存色情報を利用して応用可能にする。
全ブランド共通マスターの方針を維持。色見本は案内用近似色であり厳密なブランド色再現不要。
候補ソース meodai/color-names https://github.com/meodai/color-names （約32000色、CSV/JSON、ライセンスとデータ由来を確認して固定版保存）、XKCD https://xkcd.com/color/rgb/ （954色、利用条件確認）。XKCD moss green #658b38 等は名称と値の実例。既存パレットを優先して維持。辞書は商品ごとにHTTPアクセスせず一括取得・ローカルキャッシュ・版/hash/出典/利用条件保存。商用利用可否を確認できるデータのみ利用。
Python処理：色名原文の構成順を保持し、ユニークな正規化トークン単位で 1既存マスター完全一致 2外部辞書完全一致/明確な別綴り 3色名内の明示的基本色・店Colorタグとの整合による基本色近似 4未解決語だけ外部色辞書追加検索・ブランドの色名情報を参照し根拠のある近似候補 5判定不能はUNKNOWN（推測したHEXで確定しない）。曖昧な文字列類似だけで別色にしない。複数タグを順番で未解決語に割り当てない。辞書値が競合したら固定優先順位・出典記録、既存確定値を自動上書きしない。商品画像の目視作業・画像の大量取得/解析を必須にしない。色名ごとの一度の判定を全店舗・全ブランドへ再利用。BUYMA分類は公式マスターと主色根拠を別途保持。表示近似色の自動採用とBUYMA確定を混同しない。
担当：Python担当が辞書取込・照合・キャッシュ・出力を実装。Museは実行と集計確認のみ、個別色判定を担当しない。少数見本→全11777件のオフライン候補生成、未解決ユニーク語数/解決率/出典別集計、再実行一致・原本保全を確認。実辞書取得・ライセンス検証・Python実行は未実施。本番反映なし。
