# 色ID重複の修正報告（2026-11-19、魔王ちゃん）

対象：GPT検収（対象コミット f50009d2）で指摘された color_id 重複71件の修正。

## 1. 原因

全件処理の新規採番で、COMMON の採番範囲（C-1005〜C-2072、1,068件）と BRAND の採番範囲（C-2002〜C-2589、588件）が C-2002〜C-2072 で重なった。範囲の開始位置だけ決めて、上限の重なりを確認していなかったのが原因。

## 2. 修正内容（GPTの指示どおり：既存の正しいIDは維持し、衝突したIDだけ再採番）

- 衝突した BRAND 71件（ADIDAS Alumina など）を C-2590〜C-2660 へ再採番した。COMMON 側の ID は変更していない。
- 商品カラー側の参照も同時に修正した。対象は189商品・214コンポーネント（ブランドとトークンの両方が一致するものだけを置換し、COMMON 側の正しい参照には触れていない）。
- 修正は生成CSV（color_master_new.csv／product_color_full.csv）と実シート（カラーマスター／商品カラー）の両方へ反映した。カラーマスターの該当行には、再採番した旨と旧IDを備考へ記録した。

## 3. 検証中に見つけた追加の重複1件

GPTの集計対象（新規CSV）には含まれていなかったが、実シート全体で検証したところ、既存行との重複がもう1件あった。

- 既存 BRAND 行 C-2001（NIKE concord、fixture投入分）と、新規 COMMON「urban orange」の C-2001。
- 既存行を維持し、urban orange を C-2661 へ再採番した。商品カラー側の参照1商品も修正済み。

## 4. 検証結果（実シートの読み戻しで確認）

- カラーマスター全1,669件の color_id がすべて一意になった。
- 商品カラーの全24,299コンポーネントを照合し、参照先IDとトークンの不一致は0件。
- シートと修正後CSVの components_json の差分は0件。
- color_id が null のコンポーネントが35件ある。全て NEW BALANCE の Phantom で、マスターには NIKE 範囲の Phantom（C-0007）しかないため、範囲外として意図的に null にしたもの。壊れた参照ではない。GPTの優先リスト2位（Phantom、在庫あり51件）の解決時に、BRAND 行を作って埋める想定でいる。この扱いでよいか確認してほしい。

## 5. 残りの検収指摘への対応予定

- 丸窓 CONFIRMED 6,827件の根拠検証（未承認の色コードや基本色による代替表示を、確認済みとして扱っていないか）は、別途検証して報告する。
- 未解決トークンの解決（在庫あり件数が多い順：Chrome、Phantom、Off Noir など）と、172件の共通原因ごとのまとめ処理は、上記の検証の後に進める。
