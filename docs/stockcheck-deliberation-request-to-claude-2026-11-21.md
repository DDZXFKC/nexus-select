## 3. 審議対象：未決定3点とGPT案

### a. 在庫確認の自動期限切れ

- **GPT案：48時間**（受付から48時間で、未完了の問い合わせだけを自動クローズする）
- 根拠：これは法律で定められた期間ではなく、サービス運用上の設計値。5分以内の三値回答、UNKNOWN時の1時間後／6時間後の再確認、24時間の例外通知という処理サイクルを前提に、少なくとも24時間の未解決処理をカバーし、処理を引きずる14日より短い48時間とする。例外処理中・顧客が返信した新しい問い合わせは「処理継続」として別扱い。なお「確保可」は在庫予約ではなく、48時間の在庫保証を意味しない（注文確定前に在庫・価格・送料・税を再照会する）。
- 現行の初期値：14日（現行プラグインの初期値。オーナーの最終承認前に書き換えない前提）

### b. 完了後の保持期間

- **GPT案：90日**（対応終了から90日間を標準とする）
- 根拠：未購入の在庫確認フォーム情報の削除方針として、問い合わせの再照会・二重対応の調査・応対品質の短期検証を想定した運用上の提案であり、法定期間ではない（個人情報保護法に一律の保存日数の定めはなく、目的終了後に不要となった個人データは遅滞なく消去する努力義務がある）。より短くできる業務なら短縮すべき、という留保つき。クレーム・購入済み注文・会計証憑・法律に基づく保存義務のある記録は別ポリシーで保持し、消去対象からすべての業務記録を一律に除去はしない。
- 現行の初期値：6ヶ月（現行プラグインの初期値。オーナーの最終承認前に書き換えない前提）

### c. 複数買い付け先への対応

- **GPT案：設計に入れることを推奨**。内容は以下のとおり。
  - 優先順位の「安い」は値札や店頭価格ではなく、商品単位の**日本向け着地総額**（現地送料・現地税・為替・関税・輸入消費税・代行費・決済／販売手数料などを積算した見込額）を比較可能な条件で比べたものとする。未確定費用をゼロ扱いしない。不明コストの店は比較不能として別キューに置く。クーポンは「条件適合暫定」と「実測確認済み」を区別し、未実測の割引だけで確実に最安と断定しない。
  - 比較可能な店を**着地総額の安い順**に照会し、**最初に在庫が確定した店の現在価格**（現在確認した値札・送料・税・利用可能な割引と費用）で**原価を再計算**する。
  - 再計算の結果、**最低利益・販売価格の条件を満たさなければ、「在庫あり」とは返さず**、次候補または要確認に回す。
  - **全候補が確実に品切れのときだけ全体を OUT_OF_STOCK** とする。一部の店が OUT_OF_STOCK でも他店に UNKNOWN が残れば（在庫あり確定の店がない限り）全体は UNKNOWN とし、商品全体を品切れと返信しない。比較対象が1店もない場合は UNKNOWN。
  - 5分以内の返信制限を超えそうなら UNKNOWN（確認中）に切り替える。
  - **表示済み販売価格は無断で更新しない**（価格が下がるという理由だけでも同様）。計算結果とオーナー確定の価格設定ルールは分離する。選定店・実価格・追跡元URL・時刻・算出条件・返信結果は記録する。

## 4. Claude設計v2の現状（GPT案との関係）

対象：`docs/stock-check-auto-flow-design-v2-claude-2026-11-20.md`（設計v2）

- **a・bの数値は設計v2に未記載**です。設計v2は「受付期限切れ」「保持期間削除」を段階1の資産として残すことに触れていますが、具体的な数値は定めていません（現行プラグインの初期値は14日／6ヶ月）。
- **cは設計v2に仕組みがありません**。設計v2の StockChecker は `check(url, shop, variant)` という単一の買い付け先URLを前提にしたインターフェースで、1つの商品に買い付け先が複数ある場合の照会順序・全体判定・原価再計算の仕組みは含まれていません。
- 設計v2の既存フロー（今回の審議でも土台になる部分）：
  - 判定は3値（IN_STOCK／OUT_OF_STOCK／UNKNOWN）
  - UNKNOWN時は即時リトライ（5秒後・30秒後、キャッシュ不使用）、未解決なら「確認中」メール
  - その後1時間後・6時間後に再試行し、解決すれば追送
  - 受付から24時間未解決の場合は運営へ例外通知
  - ワーカーはcronで1分ごとに起動し、未処理の依頼だけを見る。依頼1件につき原則1回取得、キャッシュ30分

なお、オーナー協議による設計追加メモ（価格変動の伝え方、複数買い付け先の追加案、パラメータの扱い）も別途あります。本依頼とあわせて参照してください。
