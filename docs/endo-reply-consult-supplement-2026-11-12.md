# 補足相談：有料WooCommerceコンテンツの購入（2026-11-12）

docs/endo-reply-consult-2026-11-12.md の相談への補足。ユーザー（ノリぴろ）の追加の意向。

- 補助金の計画（オリジナルTシャツ販売）の中で、WooCommerceに取り入れる有益な有料コンテンツ（有料プラグイン・拡張機能など）の購入も候補に入れたい、という意向が追加された。
- 前提：購入は交付決定後。現行の自サイト運用では「有料プラグインは現段階では買わない」が既定だが、補助金の経費として入れる場合はその限りではない。
- 既決事項（蒸し返さないこと）：注文追跡は自作プラグインNEXUS ORDER TRACKER中心の無料構成が採用済みで、OSMは機能が重複するため購入しない。AST PROは同一商品の数量分割の実需が出た時点で単体追加を検討する、が既定。
- 相談：Tシャツ販売（自社EC）に効く有料拡張で、上記と重複しないものがあれば候補を挙げてほしい。ウェブサイト関連費に上限や条件があるかも含め、持続化補助金＜一般型＞第20回の公募要領ベースで整理してほしい（断定できない部分は事務局確認事項に切り分け）。
