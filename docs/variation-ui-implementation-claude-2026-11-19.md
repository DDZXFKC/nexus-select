## 修正（GPT監査 c2d058d の1・5への対応、2026-11-19）
- 色見本の画像は「そのバリエーション自身の画像」だけを使うように変更（get_image_id('edit') は親画像に置き換わらない）。自分の画像がない色は、他の色の写真を借りずに従来の色の丸で表示する。
- 同じ画像が2つ以上の色に付いている場合は、どちらの色にも使わない（誤った色の表示を防ぐ）。
- get_available_variations() を追加で呼ぶのをやめ、子バリエーションを直接読むようにした（大量バリエーション時の負荷対策）。
- 変更は mu-plugins/nexus-variation-gallery.php のみ。Museは反映済みのこのファイルを差し替えて、実機確認に含めてほしい。

## 修正2（オーナー指摘「画像の切り抜き、イマイチだな」への対応、2026-11-19）
- 色見本の画像を、商品の写っている範囲に合わせて自動で拡大・位置合わせするようにした。白い背景を除いた商品の範囲を測り、その範囲が丸の約9割を占めるように表示する（靴が下に寄っていても丸の中央に来る）。
- 丸の大きさ・形・配置は変えていない。
- 画像が読めない場合（別ドメインの画像など）は、固定の拡大（170%・やや下寄せ）で表示する。
- 拡大してもぼやけないよう、色見本に使う画像を一回り大きいサイズ（woocommerce_thumbnail）に変更。
- 変更ファイル：theme/main.js、theme/style.css、mu-plugins/nexus-variation-gallery.php（3つとも差し替え）。
- 確認してほしい点：Air Jordan 1 Mid SE の3色で、靴が丸いっぱいに大きく見えるか。色見本が白いだけ・黒いだけになっていないか。

## 修正3（オーナーの意図「商品画像の真ん中あたりを切り抜く」に合わせる、2026-11-19 06:32の言葉）
- 修正2は「商品全体を丸いっぱいに収める」形で、オーナーの意図（商品の真ん中あたりを切り抜く）とずれていた。
- 修正3：商品の写っている範囲の中心に合わせ、丸には商品の真ん中あたり（商品の短い辺の約半分の範囲）だけが映るように拡大する。白い余白は丸に入らない。
- 画像が読めない場合の代わりの表示も、画像の中央を3倍に拡大した切り抜きに変更。
- 変更ファイル：theme/main.js、theme/style.css（mu-pluginは修正2のまま）。

## 修正4（オーナー決定「サンプル第2弾の方式＝靴の部分だけ」に合わせる、2026-11-19、62f42de）
- 切り抜き窓の決め方を「中央」から「背景を含まない領域」に変更。全商品に自動で効く（魔王ちゃんの手作業は不要）。
  1. 画像の縁につながっている白（と透明）だけを背景とみなす（塗りつぶし判定）。白い靴の中の白は商品として扱う。
  2. 商品の画素だけでできた一番大きい正方形を探す（同じ大きさなら商品の中心に近いもの）。丸はその正方形の内側に収まるように拡大するので、背景の白は丸に入らない。
  3. 使える正方形が見つからない画像だけ、中央を拡大する代わりの表示。
- 合成画像で確認：黒い靴・白い靴（輪郭あり）とも、正方形は靴の内側に取れ、丸（36px）は正方形（40px）の内側に収まる。真っ白な画像は代わりの表示になる。
- 変更ファイル：theme/main.js のみ（style.css・mu-pluginは修正3のまま）。
