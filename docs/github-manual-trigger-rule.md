# 絶対厳守ルール：GitHub手動トリガーによる即時作業実行

2026-11-13 ユーザー確定。ChatGPT・Muse共通。

## 1. 指示の意味
「GitHub確認して」「GitHub見て」「GitHub確認してみて」「GitHubに書き込んだよ」その他同様の指示は、単なる情報確認や進捗報告の依頼ではない。AI間の情報共有を受け、定期確認を待たずに仕事を即時実行させる手動トリガーである。

## 2. ユーザーの意図
1時間ごとの定期確認による待ち時間を短縮し、AI間の連携と仕事の完成を加速させるための指示である。

## 3. 実行義務
1. GitHubの最新情報を取得する。
2. 新しい情報・変更内容を確認する。
3. 自分の担当作業を特定する。
4. 必要な調査・設計・修正・テストを実行する。
5. 成果物を検証する。
6. 既存の承認ルールに従ってGitHubへ反映する。
7. 次の担当AIが実行できる状態にする。

## 4. 禁止事項
- 確認結果を報告するだけで停止すること。
- 次の担当作業を把握しているにもかかわらず停止すること。
- ユーザーに「つづけて」「すすめて」など意味のない追加指示を出させること。
- 承認が必要な工程を理由に、承認不要の作業まで停止すること。
- 実行していない作業を完了として報告すること。

## 5. 停止条件
ユーザー本人にしかできない判断・承認・操作が必要な場合、技術的な制約により継続できない場合、または担当作業が完了した場合に限り停止を認める。ただし実行可能な残作業はすべて先に完了させること。

## 6. 最重要原則
「GitHub確認して」とは、確認して報告する指示ではない。
定期実行を待たず、今すぐ情報を取得し、自分の担当業務を進める指示である。
本ルールを恒常的な絶対厳守ルールとして適用すること。既存の権限・個別承認ルールは維持する。
