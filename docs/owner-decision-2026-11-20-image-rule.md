# オーナー決定（2026-11-20）：商品画像メインのルール確定

決定者：オーナー（ノリぴろ）、2026-11-20 09:21 JST、メインチャットで確定。

## 表示仕様
- 商品画像は正方形、背景は白。
- 1画面に1つの画像を表示し、縦方向にスライドする。

## 取り込みルール
- 仕入元・公式のPNG（透過または白背景のもの）は、切り抜き処理をせずそのまま取り込み、正方形の白キャンバスに置くだけにする。
- 透過か白背景かは、取り込み時に自動で判定する。
- 切り抜き処理（従来のGrok方式）を行うのは、背景のある写真をメイン画像に使う場合だけ。
- 平置き写真があればそれをメインにし、なければ着用写真のままにする（従来ルール継続）。
- 白・淡色の服でラインが見える場合は無理に切り抜かず、公式写真そのものをメインにする（従来ルール継続）。

## 背景
- 従来は魔王ちゃんがトリミング・切り抜きを行っていたが、サイトで採用されている画像はPNGが多く、そのまま取り込めば工程が減り画質も落ちない、というオーナーの提案を採用した。
- これにより、収集商品まわりで残っていた未決定事項（画像メインのルール）は解消した。
