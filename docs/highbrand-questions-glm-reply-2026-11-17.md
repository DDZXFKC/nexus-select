## 問い1：なぜハイブランドとありさんが結びついているのか

**ありさんに買い付けてもらうのが1番利益になるからではありません。**

理由は2つあります：
1. **オンラインで買える商品は、オーナーが直接買う（ルートB）方が利益率が高い**です。VATがかからず、仲介手数料も発生しません。
2. **ありさんの価値は「利益率」ではなく「オンラインでは買えない商品を扱えること」にあります。** 店頭限定品、アウトレットのセール品、日本未入荷品などは、ルートB（オンライン）では拾えません。これらを狙うための唯一の実店舗パートナーがありさんであるため、話が具体化しました。

つまり、**ルートB（オンライン・オーナー直接）＝利益率重視の定番品、ルートA（ありさん・店頭）＝オンラインで買えない限定品、という使い分け**であり、ありさんが「最も利益が出るから」主役になっているわけではありません。

## 問い2：今やる必要があるのか、資金が貯まってからでよいのか

**明確に切り分けます。**

### 今やること（支出0円・既存事業と並行）
- **仕入先・商品の調査**: プラダ・グッチ・コーチ・エルメスについて、日本と欧州の価格差、国内需要、競合状況を公開情報で調べる。
- **ドイツからの出品者調査**: BUYMA等でドイツを買付地とする出品者の商品を参考に、何が売れるかを調べる。
- **採算計算の準備**: 共通採算式（関税・消費税・送料を含めた実原価と利益の計算式）を整えておく。
- **ありさんとの連携体制の準備**: 共有シートの設計、独立シート（原価・利益は非公開）の仕組みづくり。

※これらは**すべて無料でできます。** 資金が0円でも進められます。既存の収集Pythonやストリート事業を止める必要もありません。

### 資金が貯まってからやること（100万円の目安）
- **Phase 1（1件の実取引）**: 実際に買付けて、出品して、売って、利益を出す。1件目は自己資金で払える1注文のみ。
- **Phase 2（月3〜5件への拡大）**: Phase 1で利益が出たことを確認したうえで、オーナーが「軌道に乗った、資金が100万円ある」と判断した段階で本格展開する。

### まとめ
| 今やること（支出0円） | 資金が貯まってからやること |
|---|---|
| 仕入先・商品調査 | 実際の買付・出品・販売 |
| 採算計算式の準備 | 月3〜5件への拡大 |
| ありさん連携シートの設計 | 本格展開（100万円） |
| ドイツ出品者調査 | |

**オーナーの「資金が貯まってからでいい」という方針と矛盾しません。** 今やるべきは「お金を使わずに、商品とルートの目処を立てておくこと」だけです。実取引は資金条件とオーナーの判断を満たしてから行います。
