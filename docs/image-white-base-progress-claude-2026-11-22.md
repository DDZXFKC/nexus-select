## 対象
- 四隅が透明の正方形 PNG をメイン画像に持つ商品：420 件（FL・MERGED・NOTRE・PT ほか）。すべて可変商品。

## やり方
1. 元の画像は変えない・消さない。
2. 1 枚ずつ、同じ大きさの白い正方形の上に元の PNG をそのまま重ね、新しい添付画像として登録する。
   - ファイル名は `<元の名前>-white.png`。代替テキストも元の画像から引き継ぐ。
   - 切り抜き・色の加工はしない。
3. 全部登録し終えてから、420 商品のギャラリーとサイズ別画像を、元 ID から新 ID に付け替える。
   - 並び順は変えない。
4. 付け替えの記録（元 ID → 新 ID）を GitHub に残す。元に戻すときに使う。
