## 0. 結論（先に）

- **前回の合意は「何を・どんな条件で売ってよいか」の規則であって、「どうやって買うか」が空欄だった。** オーナーの指摘どおり。
- **GLM案の利益の柱「VAT還付」は、ありさん経由では使えない可能性が高い。** ドイツの旅行者向け免税は「EU域外に住んでいる人」が「自分用に」買って「手荷物で持ち出す」場合だけで、国籍ではなく居住地で決まる（ドイツ税関 zoll.de、Global Blue等の案内）。ドイツ在住のありさんは対象外で、転売目的も対象外。
- だから利益の出し方は2本に分かれる。
  - **A：ありさん店頭買い（VAT込みで払う）** → 関税込みで**約1.7倍前後**が必要（§7で修正）。補助ルート。
  - **B：欧州の正規オンライン販売店から日本向け（VAT抜き価格）で買う** → 自宅兼事務所で受け取り、関税・輸入消費税込みで**約1.35〜1.45倍以上**（§7で修正）。パートナー不要、デビットカードで払える。**主ルート。**
- 最初の仕事は、お金を使わずに「この倍率を満たす商品が本当にあるか」を数えること（Phase -1）。**5点見つからなければハイブランドは見送り、ストリートに集中する。** ここで止める判断も「答え」に含める。

## 1. 問い2：なぜ前提の欠落に誰も気づかなかったのか

Claude自身の原因として3つ。

1. **問いの形のまま答えた。** 開始文書の問いは「扱うか・対象範囲・仕入先条件・規制・資金・MVP」。3者とも各項目を埋めることに集中し、「その答えは実行できるか」を確かめる項目がなかった。Claudeは「正規仕入先の証拠」を出品条件に入れたが、**その正規仕入先に実際に手が届くかは一度も確かめていない。**
2. **スニーカーの仕入れ網を、ハイブランドにも使える前提で読んだ。** Foot Locker・BSTN等の実績があるため、「どこかで買える」と無意識に置いていた。実際はハイブランドの仕入れ実績はゼロ、米国パートナーは店舗買い付けをしない、ありさんは未稼働。
3. **1件の注文を最初から最後までなぞる確認をしなかった。** 「誰が・どの店で・何で払って・税金はどうなり・どう日本に届き・関税は誰が払うか」を1件だけでも書けば、空欄にすぐ気づいた。

再発防止（3者共通ルールとして提案）：
- 事業判断の審議では、**必ず「注文1件の流れ」を書き、各段に「確認済み／未確認」を付ける。** 未確認が1つでも残る案は「実行可能」と書かない。

## 2. 問い1：前回の答えが今後のビジネスに与える影響

**良い面（残して使えるもの）**
- 「正規店・新品のみ」「二次流通のプレミア品は扱わない」「商品ごとに差止・規約を確認」「証跡の保存」「無在庫」は、どの仕入れルートになっても使える。コンバースの件のように、出品後に問題が出るのを防ぐ。

**悪い面（具体的に）**
- **そのまま実行していたら：** BUYMAに出品 → 注文が入る → 買える人・店が決まっていない → キャンセル。BUYMA再開の立ち上げ期にキャンセルが出ると、ショップ評価に直接響く。ストリート商品の売上まで巻き込む。
- **「1点15万円・同時1注文」という上限は、根拠がなかった。** 1点の原価もルートも未計算のまま数字だけ置いた。
- **審議の時間を使った。** 収集Pythonやクーポン部品など、売上に近い作業の時間を削った。

## 3. 前提づくり：注文1件の流れ（ルート別）

| 段 | A：ありさん店頭 | B：欧州正規オンライン（日本向け） |
|---|---|---|
| 誰が買う | ありさん | オーナー（自分の名前で注文） |
| どこで | ドイツの直営店・正規店 | ブランド正規取扱のオンライン店（EU/英国） |
| 何で払う | オーナーが事前送金 → ありさん（立替を避ける形） | オーナーのデビットカード |
| VAT | **払う（19%）。旅行者免税は使えない**（居住地がEU内・転売目的のため） | 日本向けはVAT抜き価格になる店が多い（店ごとに要確認） |
| 日本への送り | ありさんが国際発送 | **店からオーナーの自宅兼事務所へ直接発送**（オーナー決定）→ 検品・証跡保存 → 国内発送 |
| 関税・輸入消費税 | 購入者負担にするか要決定 | **オーナーが輸入者として払う → 原価に入れる**（出品価格は関税込み） |
| 未確認 | 店頭で買えるか／購入制限／店が日本企業宛て請求書と輸出手続きをしてくれるか（ほぼ期待しない） | 対象商品を日本に送るか／日本のデビットカードが通るか／BUYMAで買付先として認められるか |

補足：
- 英国（ピアース千恵さん）は2021年に旅行者免税自体を廃止しているので、Aと同じくVAT込み前提。英国のオンライン店の日本向けVAT抜き価格はBと同じ扱い。
- B（オンライン購入）は**自宅兼事務所経由で確定**（オーナー指示 10:52）。ありさんはオンライン購入には関わらない。合意の「発送前ゲート」（実物検品）もこれで守れる。関税・輸入消費税はオーナー負担になるので、§7の修正計算を使う。

## 4. 数字の例（€500の商品、現行式の形をそのまま使う）

注意：現行式の158はUSD/JPY。ユーロには使わない。ここでは**EUR/JPY＝175を仮値**とし、実勢で置き換える。0.745の内訳（BUYMA手数料と利益の配分）は未確定のまま。

**A：ありさん店頭（VAT込み）**
- 500×175×1.02 ＝ 89,250
- ＋ありさん買付2,000 ＋ありさん発送1,000 ＋国際送料6,000（GLM仮値）＋梱包60 ＝ 98,310
- 出品価格 ＝ 98,310 ÷ 0.745 ≒ **131,960円**
- 欧州税込価格（500×175＝87,500円）の **約1.51倍**。日本の定価・相場がこれ以上でないと売れない。

**B：オンライン・日本向けVAT抜き**
- 500÷1.19 ＝ €420.17 → ×175×1.02 ＝ 75,000
- ＋送料3,000（仮値）＋国内転送1,000（オーナー受け取りの場合）＋梱包60 ＝ 79,060
- 出品価格 ＝ 79,060 ÷ 0.745 ≒ **106,120円**
- 欧州税込価格の **約1.21倍**。ただし関税・輸入消費税は含まない（購入者負担の前提）。

GLM案との違い：
- GLMの「VAT還付後74,300円」はルートAでは成立しない可能性が高い。GLMの「還付なしなら約89,500円で利益消滅」の方が、ありさんルートの実態に近い。
- GLMの「粗利＝出品価格−仕入総額＝25.5%」は、BUYMA手数料を引く前の数字。手取りの利益はもっと小さい。

**倍率は為替をいくつにしてもほぼ変わらない**（固定費が小さいため）。だから判定は「日本価格 ÷ 欧州税込価格（円換算）」で行える。

## 5. 利益を出すまでのロードマップ

### Phase -1：ルートと商品の存在証明（今週〜11月末、支出0円）
やることは3つ。オーナーの作業は最小限。
1. **価格倍率表を作る（3者の仕事）**：第一候補ブランドの現行品10〜20点について、日本公式価格・欧州公式税込価格・欧州正規オンラインの日本向け価格を並べ、倍率を出す。公開ページを手で確認する範囲で、許可のないスクレイピングはしない。
2. **ありさんに3点だけ確認**：①対象ブランドの店で購入制限なく買えるか、②店が日本向け輸出（請求書・輸出書類）に応じるか（応じない前提で聞く）、③1回の国際発送の実費。
3. **Bの条件確認（3者の仕事）**：候補店が対象商品を日本に送るか、日本発行のデビットカードが使えるか、BUYMAで買付先として問題ないか。

**次へ進む条件**：A（1.5倍以上）またはB（1.2倍以上）を満たし、日本で手に入りにくい商品が**5点以上**ある。
**満たさなければ**：ハイブランドは見送り。記録を残して審議を閉じ、ストリートと収集Pythonに戻る。

### Phase 0：出品準備（12月上旬、支出0円）
- 条件を満たした商品から3〜5点を、合意済みの出品前ゲート（差止・規約・証跡・画像の権利）に通す。
- 関税を購入者負担にするか、直送かオーナー受け取りかをオーナーが決める。
- 実際の手数料率で0.745の内訳を確定し、ハイブランド用の式を別に作る。

### Phase 1：1件の実取引（12月）
- BUYMAに無在庫で出品。注文が入ったら在庫を再確認して1点だけ買う。
- **資金の目安**：€500品で1件あたり約8〜10万円が、買付からBUYMA入金まで約3〜4週間拘束される。**同時に受けられる注文数 ＝ 自由に使える資金 ÷ 10万円。** この上限はオーナーが金額で決める（前回の「15万円・1注文」は撤回）。
- 測るもの：実原価、届くまでの日数、関税の扱い、作業時間、購入者の反応。

### Phase 2：月3〜5件で回す（2027年1月〜）
- 例：1件の出品価格が約10.6万円（B）なら、「出品価格−原価」で約2.7万円。月3〜5件で**約8〜13万円**（BUYMA手数料を引く前）。
- この段階で初めて、ありさん・千恵さんのルートを増やすか、専用サイト（優先度は最下位のまま）を検討する。

## 追記：オーナー提示の対象ブランド（プラダ、グッチ、エルメス、コーチなど）を受けて

ブリーフへの追記（10:48）を読んだうえでの補足。Phase -1の倍率表はこの4ブランドから始める。
- **プラダ・グッチ**：ルートA・Bとも候補。ただしブランド公式オンラインは国ごとにサイトが分かれ、日本からは日本価格で売られるのが普通なので、Bは「ブランド正規取扱のマルチブランド店」が対象になる。取扱の有無・日本発送の可否は店×商品ごとに確認。
- **エルメス**：正規のオンライン取扱店が無く、店頭も人気品は購入制限・購入履歴の条件があると言われる。前回合意の「限定購入資格・購入制限の厳しい商品は対象外」「高額バッグは対象外」に当たる品が多い。**バッグ以外（スカーフ・小物・靴など）で、店頭で普通に買えるか**をありさんへの確認①に含める。買えなければエルメスは外す。
- **コーチ**：米国ブランドなので、**欧州ルートではなく米国ルート**（米国公式・正規店のオンライン購入 → 米国発送パートナーが受け取り・検品・発送）が自然。スニーカーと同じ仕組み・同じ式（USD×158）が使えるので、4ブランドの中で**最も早く試せる**可能性がある。米国パートナー確定が条件。

（数値の倍率基準 1.5倍／1.2倍 は変えない。コーチは現行の米国式で個別に計算する。）

## 7. オーナー訂正（10:52）を受けた修正：ルートBの原価に関税・輸入消費税を入れる

オーナー指示：「ドイツのオンラインで買うときは直接日本。自宅兼事務所を経由する。」
- VAT還付の問題は**オンライン購入（ルートB）では起きない**。日本向けの輸出販売なので、店は最初からVAT抜きで売る（「還付」ではなく「最初から課税されない」）。ありさん（ルートA）は店頭買い付けだけで、VATとは別の話。§0・§4のVAT議論はルートAだけに当てはまる。
- その代わり、オーナーが輸入者になるので、**関税と輸入消費税（10%）を原価に入れる必要がある**。§4のBの計算（約1.21倍）はこれを入れていないので**差し替える**。

**B修正版（€500税込の商品、EUR/JPY＝175仮値）**
- 商品：500÷1.19＝€420.17 → ×175×1.02 ＝ 74,970
- 国際送料（仮値）3,000 → 課税価格の目安 77,970
- ケース1：関税0%（日EU・EPAの特恵税率が使える場合）
  - 輸入消費税 7,797 ＋国内発送1,000＋梱包60 → 原価 86,827 → 出品価格 ÷0.745 ≒ **116,550円**（欧州税込価格の**約1.33倍**）
- ケース2：関税10%（衣類の一般税率の目安。品目ごとに違う）
  - 関税 7,797、輸入消費税 8,577 → 原価 95,404 → 出品価格 ≒ **128,060円**（**約1.46倍**）
- 革靴は一般税率が高い（30%または1足4,300円の高い方）ので、EPAが使えないとほぼ不成立。
- 出品価格は関税込みなので、購入者に追加負担はない。日本の税込定価と直接比べられる。

**判定基準の修正**
- ルートB：**欧州税込価格の約1.35倍（EPA適用）〜1.45倍（関税10%）以上**。品目の関税率で変わる。
- ルートA（ありさん店頭）も同じく関税・輸入消費税が乗るので、1.5倍ではなく**約1.7倍前後**が目安になる。Bより明らかに不利なので、**ハイブランドの主ルートはB（オンライン→自宅兼事務所）**とし、Aは「オンラインに無い商品の補助」に下げる。

**新しく確認すること（Phase -1に追加）**
1. 日EU・EPAの特恵税率を使うには原産地の証明が要る（店の請求書の原産地申告、または輸入者自身の知識による申告）。小売店の請求書に原産地申告が付くか、付かない場合に輸入者側で申告できるか。→ 使えなければケース2で計算。
2. 店によっては日本向けを「関税・税込み（DDP）」で売っている。その場合は表示価格に関税・消費税が入っているので、二重に足さない。
3. オーナーが消費税の課税事業者かどうか。課税事業者なら輸入消費税は仕入税額控除の対象になり、実質の原価から外れる（ケース1で約1.24倍まで下がる）。

（関税率・EPAの扱いはClaudeの一般知識による目安。実際の品目分類と税率は税関の事前教示か通関業者で確認すること。）
