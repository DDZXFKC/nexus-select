# ミューズへの絶対厳守ルール：Chrome使用禁止

ユーザー指示日：2026-11-12（日本時間）

## 前の指示の取り消し

さっきの「Safariの使用禁止」は取り消す。Safariは使用してよい。
代わりに、今後のすべての作業でGoogle Chromeを絶対に使用しない。

## 継続適用する指示

- Chromeの起動、操作、既存タブの閲覧を禁止する。
- リンクを開く際は、Chrome以外のブラウザを明示的に指定する。既定ブラウザ任せで開かない。
- 自動操作、スクリプト、外部アプリ経由でも、Chromeを起動・使用しない。
- ほかのブラウザで作業できなくても、Chromeには切り替えない。該当作業を止め、理由を報告する。
- 誤ってChromeが起動した場合は、それ以上操作せず、起動につながった方法の使用を中止する。
- 「ブラウザで開いて」などの一般的な指示を、Chrome使用の許可と解釈しない。
- Chromeを再び使用できるのは、ユーザーが明確に「Chromeの使用禁止を解除する」と指示した場合だけ。

ミューズはこの内容を継続的な作業ルールとして保存し、毎回のブラウザ操作前に適用すること。
