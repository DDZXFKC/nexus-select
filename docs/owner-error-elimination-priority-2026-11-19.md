# オーナー指示：エラー解消最優先
2026-11-19「とにかく今はエラーをなくすことに専念」

GPT・Muse・Claude・GLM共通。新機能追加・デザイン変更より既存機能のエラー解消と安定化を優先する。収集、価格・原価、サイズ、カラー、在庫、商品登録、表示・動作の不具合を共通原因別に整理し、修正・回帰テスト・実データ検証まで行う。未知値や失敗を隠して合格にしない。独立した修正は並行し、既存の安全ゲートを維持する。全店舗販売可能化を目標とする。

海外お取り寄せ・在庫確認方式（docs/owner-mandatory-storefront-purchase-flow-2026-11-19.md）は必須完成仕様として保持するが、今は実装しない。既存の公開条件・承認ルールは維持。Museは優先順位をリマインダーに反映し、各担当に共有する。
