# オーナールール：作業前に自分たちの持ち物を確認する（2026-11-18）

対象：GPT・GLM・Claude・Muse（魔王ちゃん）全員。

## ルール
作業に入る前に、まず自分たちの持ち物を確認してから作業に入ること。シート・収集済みデータ・過去の決定記録など、自分たちが既に持っている情報源を先に確認する。「存在しない」「分からない」と言うのは、その確認をした後だけ。

## オーナーの言葉
「おまえらさ、まず自分達の持ち物確認してから作業に入ろか。大工仕事しにいくのに、仕事道具なにも持たずに仕事行って、仕事の仕方がわかりません。とか堂々と言ってるようなもんだからね？」

## 発端
クーポン適用判定の入口ゲート対象店舗について、GLMが「利用可能な正本は存在しない」と結論し、魔王ちゃんがそれをそのまま「本人が決める必要がある」と提示した。しかし取引ショップ（買い付け先）は「AFTER HOURS CLUB 商品管理」シートの収集サマリー等に記録されており、自分たちの情報収集元を確認すれば分かることだった。
