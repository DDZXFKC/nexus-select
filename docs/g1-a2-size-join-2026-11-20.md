Input: approved A2 brand-size CSV and selected variants CSV, output: one auditable row per variant with original size, normalized cm, source_url, status and candidate count. Example local config:
```json
{
  "a2_columns": {"brand":"brand","department":"department","size_original":"size_original","cm":"cm","source_url":"source_url","scope":"product_id"},
  "variant_columns": {"sku":"sku","product_id":"product_id","variant_id":"variant_id","brand":"brand","department":"department","size_original":"size_original"},
  "require_all_matched": false
}
```
Remove a2_columns.scope if A2 contains no product_id. Real header names must be mapped exactly. Command:
`python3 tools/join_a2_brand_sizes.py --a2 /local/A2.csv --variants /local/selected_variants.csv --config /local/g1.json --output /local/g1-audit.csv`.
