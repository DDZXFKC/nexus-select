# 商品画像の枠・背景 監査：実行依頼（Claude、2026-11-21）

引き継ぎ（オーナー決定 2026-11-21）で、商品画像の監査と是正はサイト担当の Claude が担当する。
ルールは「正方形・白背景・1画面1画像」（docs/owner-decision-2026-11-20-image-rule.md）。
Claude はサーバーに入れない（パスワードを入力しない決まり／作業環境から外部サイトへ接続できない）。そのため、読み取り専用のスクリプトを用意した。**サーバーで1回実行し、結果の CSV を GitHub に上げてほしい。**

## サイト側の現状（コードで確認済み）
- 商品ページの画像枠は、CSS（theme/style.css の `.nexus-gallery`）で正方形・白地・画像は切らずに収める（object-fit: contain）になっている。
- したがって「ベージュ背景・横長」に見えるのは、**画像ファイル自体**がベージュ地・横長だから。直すのはファイルで、CSS ではない。
- 実際のサーバーの CSS が正本と同じかは、Claude は未確認。CSV の結果と実画面が合わない場合は、CSS 側も疑う。

## 実行方法（読み取り専用。変更は一切しない）
```bash
# WordPress のルートで
wp eval-file <リポジトリの tools/audit_product_images.php> out=$HOME/ahc-image-audit.csv
# まず試しに: ... limit=20
# 下書き等も含めるなら: statuses=publish,private,draft
```
- 書き込むのは out= の CSV だけ。WordPress の公開ディレクトリの中には書かない（中を指定すると止まる）。
- 画面に件数のまとめが出る（products=… products_with_issue=… OK=… PAD=… CUTOUT=…）。
- CSV は画像1枚ごとに1行。メイン・ギャラリー・バリエーション画像をすべて含む。商品URLも入っている。

## 判定の意味
| 判定 | 意味 | 直し方 |
|---|---|---|
| OK | 正方形で、背景が白か透過 | なし |
| PAD | 背景は白か透過だが、正方形でない | 白い正方形キャンバスに置くだけ。取り込みルールどおりで、切り抜きは不要。機械で一括処理できる |
| CUTOUT | 背景が白でも透過でもない（ベージュ・グレー・写真背景など） | 切り抜き、または白背景の公式画像への差し替え。取り込みルールで「背景のある写真をメインに使う場合だけ切り抜く」とされているもの |
| MISSING | ファイルが無い・読めない | 画像の再取り込み |
| NO_IMAGE | メイン画像が設定されていない | 画像の設定 |

- 判定は、画像の縁（四辺）の色で決める。
  - 白：RGB 各245以上
  - 縁の90%以上が白か透過なら、白背景とみなす
- 商品が画像の端まで写っている場合は、白背景でも CUTOUT と出ることがある。CUTOUT は、是正前に一覧で目視確認する。

## 結果を受けて Claude がやること
1. CSV を集計し、判定ごとの件数と、CUTOUT の商品一覧（URL付き）をオーナーへ出す。
2. PAD の一括是正（白い正方形キャンバスに置く）の手順とスクリプトを用意する。
   - 元画像を残す
   - バックアップを取る
   - 少数で試して実画面で確認してから全件
   - 実行と実物確認は、サーバーに入れる人と一緒に行う
3. CUTOUT の扱い（切り抜きか、公式白背景画像への差し替えか）は、件数を見てオーナーが決める。
