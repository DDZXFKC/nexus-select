## 2つ目：情報を修正するPythonの直す項目（確定）
稼働タイミング：常時稼働ではない。収集の後、シート精査の後、レイヤー集計・サイト取り込みの前に、店舗ごと・収集バッチごとに実行する。

直す項目：
1. cm換算を足す（店のデータにはcmが無い。自前のブランド別サイズ換算表を引く。UGG乳児サイズ等の換算表の不足行が欠落の原因だった）
2. rawにはあるのにCSV／シート側へ出ていない項目を戻す：定価（compare_at_price）、出典URL、クーポン対象可否（タグ Code_FLASH30／Code_FLASH50 等）
3. 色を商品名の括弧内表記から属性として分ける
4. 件数の扱いを分ける：全商品の件数と、在庫が1サイズ以上ある商品の件数を分けて出す（混ぜると163／158のような食い違いに見える）
5. 日本語の説明文は自前で足す層として扱う（現状は英語のbody_htmlのみ）

直せないもの：
- 在庫の「数量」。Shopifyの公開データは在庫の有無のみで、店が出していない。Pythonでも取れない。

現状の実装状態：
- 集めるPython（ahc_collect）はあるが、情報を修正する専用Pythonは未実装。定期稼働の設定もない。
- この文書の項目をもとに、Grokが実装を進める。設計・監査は従来どおりGPT、完成判定もGPTの検収で見る。
