# 在庫確認の入力をポップアップにする（オーナー決定 2026-11-21）— Claude

## 決定（オーナー、2026-11-21。魔王ちゃん経由で受領）
- 在庫確認ボタンを押したら、ポップアップを出す。
- 入力は2つが必須、1つが任意。
  - 必須：メールアドレス、名前
  - 任意：メッセージ
- サイズは、お客様がサイズボタンで選んだものを自動で使う。メッセージに書かせない。

## 変更（正本 local-snapshot-2026-11-15/mu-plugins/ahc-stock-check.php、md5 2576cd7b6fcdc10e5d53c3192bdca00d）
- **ポップアップ**：商品ページの下に開いていたフォームを、ポップアップ（ブラウザ標準の dialog）に変えた。
  - 中身は上から順に、次のとおり。
    - 選んだ商品・カラー・サイズ（自動表示）
    - 価格が変わりうる5つの事案の説明（オーナー決定 addendum §1）
    - 名前（必須）・メール（必須）・メッセージ（任意）
    - 送信ボタン、閉じるボタン
  - ポップアップの外を押しても閉じる。
- **確認用メール欄を削除**：オーナー決定のとおり、必須は名前とメールだけにした。サーバー側も、確認欄が無くても受け付けるようにした（送られてきた場合だけ照合する）。
  - **注意（オーナー判断用）**：結果はメールでしか届かないので、打ち間違えるとお客様に結果が届かない。確認欄は、旧GLMがそのために入れていた。外したままでよいか、もう一度見てほしい。
- **案内文**：「通常3営業日以内に返信」を「確認結果はメールでお知らせします。」に変えた。自動化前でも後でも正しい文にした。自動化を反映したら「5分以内」に変える。
- メッセージ欄の「ほかのサイズもご希望の場合は…」という案内を削除した。
