# 遠藤様への再相談文案（2026-11-21、オーナー決定反映・未送信）

件名：小規模事業者持続化補助金 第20回｜自社EC制作計画の見直しについて

遠藤様

お世話になっております。中田です。

以前提出した様式2では、自社ECサイトを私自身で完成させることを前提に計画を立てていました。しかし制作を進める中でトラブルが重なり、特に海外買付先の在庫確認、価格計算、カートとの連携といった自動化や在庫管理について、専門知識のない私一人で安定して完成・運用することは困難だと判断しました。

現在、サイトの基礎部分はサーバー上にありますが、Basic認証をかけた非公開の作業環境にとどまっており、購入に必要な機能や商品画像の整備も未完成です。そこで、当初の「自力でサイトを完成させる」という前提を見直し、専門業者に残りの制作・調整を委託する方向へ変更したいと考えています。

補助事業の内容は、以前ご提出した自社ECサイトの整備と販路開拓の計画に戻したく、経費構成はウェブサイト関連費40万円、広報費30万円、その他の外注費5万円、総事業費75万円、補助申請額50万円を基本案として見直しています。

もちろん、これまで自分で行った制作・サーバー移行や、交付決定前に発注・契約・支払をした費用を補助対象に含めるつもりはありません。交付決定後に新たに委託する未着手の制作作業を具体的に整理し、見積もりを取得したうえで計画を確定します。その他の外注費の経費区分についてもご確認をお願いしたいです。

なお、2025年分の確定申告は、事業収入を含めた青色申告書・決算書の作成を進めており、現時点ではまだ正式提出前です。申告を済ませた後に、申告書と決算書、受付の確認できる資料をご提示します。

以前ご指摘いただいた「申告書が確認できないこと」「交付決定前のサイト制作費が補助対象外となること」の2点を踏まえ、事実関係と対象経費を明確にしたうえで、様式2と様式4について改めて相談させていただけないでしょうか。

第20回の様式4発行依頼締切が12月4日であることも承知しています。お忙しいところ恐れ入りますが、進め方についてご助言いただけますと幸いです。

よろしくお願いいたします。
