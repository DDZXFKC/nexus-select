## 0. 結論
- 軸を「買付ECサイト構築」から「オリジナル商品（自社デザインのアパレル）を小ロットで作り、既存の顧客層に売る」に変える。
- 経費の中心は、シルクスクリーンの製造設備（機械装置等費）。撮影機材と有料プラグインは脇役にする。
- サイトは自己資金で自作・既に構築中で、補助対象にしないと明記する。遠藤さんが様式4を出せない理由の(2)「サイトが発注・契約済みで交付決定前の経費になる」は、この形にすれば成り立たなくなる。
- 撮影機材は「汎用品」として外されやすい。外されても計画が成り立つように組む。

## 2. 事業計画の筋（様式2の書き換え方針）

### 筋
1. 今：海外限定品の買付販売（BUYMA＋自社EC）。
2. 課題：仕入価格・為替・送料に左右され、同じ商品で価格競争になる。自社ならではの商品がなく、差別化と利益のコントロールができない。
3. 打ち手：自社デザインのオリジナル商品を、小ロットで自ら製造する。スニーカー・ストリートファッションに関心のある既存の顧客層に、買付商品と一緒に提案する。
4. 補助事業でやること：顧客ニーズの調査 → デザイン → 試作（販売しない）→ 品質の確認（洗濯・色落ち・位置ずれ）→ 少量で商品化 → 自社EC・SNSで販売。
5. 効果：仕入に依存しない独自商品の売上ができ、粗利を自分で決められる。設備は補助事業後も使い続ける資産になる。

| 項目 | 方針 |

## 3. 金額規模の目安と注意点
- 上限は補助50万円（補助率2/3）。満額なら経費75万円、自己負担25万円。ただし補助金は後払いなので、75万円（＋消費税）を一度は全額自分で払う必要がある。
- 満額ありきにしない。必要のない機器（製版乾燥など）を足して75万円に合わせるより、60万円前後で筋の通った計画の方がよい。
- 交付決定前は見積だけ。発注・契約・購入・支払いはしない（練習用の機材も買わない）。
- ウェブサイト関連費・広報費は、それぞれ補助額30万円が上限で、単独では申請できない（本案は機械装置が主なので問題なし）。
- 1件50万円（税込）を超える発注は2者以上の見積が必要。
- 新商品開発費は、テストマーケティングか市場調査の内容と結果を書かないと対象外。
- 申請要件として、補助事業後に売上高・売上総利益が増える見込みであることが必要。
- 製造場所の確認：自宅（賃貸）で露光・インク・洗浄（排水）・乾燥（熱）を使えるか、賃貸契約・換気・電源をオーナーが確認する。
- 撮影機材は、型番と用途を書いて遠藤さん経由で対象になるか照会する（12/4の様式4申請前に）。

## 4. GPT案との違い
- 方向・機器構成・注意点はほぼ同じ。
- 撮影：GPTは「確定まで申請額に入れない」。Claudeは「カメラ本体は外し、撮影専用の照明・背景・撮影台・トルソー等に絞って照会し、通れば入れる」。メイン動画はスマホ等の手持ち機材で撮る前提で、計画は撮影機材なしでも成り立たせる。
- 少額の発売告知広告（広報費）を任意で入れる案を追加。
