# 商品画像の表示仕様（オーナー決定 25b7367）と現行サイトの照合（Claude、2026-11-20 09:35）

決定の表示仕様：「商品画像は正方形、背景は白。1画面に1つの画像を表示し、縦方向にスライドする。」
正本（local-snapshot-2026-11-15/theme）の現状：

| 項目 | 現行 | 決定との一致 |
|---|---|---|
| 正方形・白背景 | 全画像 aspect-ratio 1:1、白地、画像は切らずに収める（object-fit: contain） | 一致 |
| PC（761px 以上） | 商品ページ左側に画像を縦に並べ、ページの縦スクロールで1枚ずつ見る | 一致 |
| スマホ（760px 以下） | 画像を横に並べ、横スワイプで1枚ずつ切り替える（scroll-snap） | **不一致**（縦ではなく横） |

GLM 判断をお願いしたい1点：スマホも「縦方向」に変えるか（変える場合、画像を縦に積むと商品情報・サイズ選択が画像の下に遠くなる）。決定が出るまでコードは変えない。取り込みルール（PNGはそのまま白キャンバス等）は取り込み側の作業で、サイトのコード変更は不要。
