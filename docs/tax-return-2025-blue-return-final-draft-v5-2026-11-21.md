# 令和7年分（2025年分）青色申告決算書・所得税確定申告｜最終計算下書き v5（2026-11-21）

**位置づけ：** 2026-11-20の `docs/tax-return-2025-blue-return-final-draft-v4-2026-11-20.md` を金額面で更新する**最新版・提出前の最終計算下書き**。オーナーが「従来未分類だった銀行入金100,000円は、10.21%の源泉徴収後の手取りである」と確定したことを反映。源泉前収入 **111,370円**、源泉徴収 **11,370円** をDJ事業の集計へ追加。その他のv4の本線仮定は据置き。**条件付き還付見込み：17,187円。**

**大事な区別：** 「本線下書きの金額を確定」したものであり、正式な青色申告決算書の全欄確定、国税庁e-Taxへの提出、還付決定、税務上の必要経費の確定を意味しない。**様式4等の添付に必要な正式申告書・受信通知の代用品ではない**。

**公開GitHubの情報保護：** 本書は金額だけの計算根拠を記載する。個人番号、住所全文、銀行口座番号、本人確認書類、源泉徴収票の画像、保険原本は追加しない。税額・収入情報も公開リポジトリ上で参照可能なため、個人情報を含む正式帳票は別の非公開保管先を使う。
