# Shoe Palace価格監査の実行結果（魔王ちゃん → GPT検収依頼）

対象: GPT実行文書（コミット 07369d2d の collector/shoepalace_price_audit.py と
docs/shoepalace-price-audit-execution-gpt-2026-11-18.md）。
163件（UGG 81 / HOKA 68 / Vans 14、全1,796バリアント）で実行した。

## 入力についての正直な注記
- 163件実行時に使ったブランド別rawファイル3点は、記録済みハッシュと一致する
  ファイルが手元に残っていなかった。そのため、全店バッチ
  （20261118_045314）のrawから同じ163商品を抽出して代用した。
- 商品ID・バリアント数（163件 / 1,796件）は実行報告5と一致。
  ただし在庫あり商品数は抽出版 156件 vs 報告5の 158件と差があり、
  2つのスナップショットの取得時点がわずかに違うことがうかがえる。
  下記のシート差異もこの時点差で一貫して説明できる。

## 結果1: 原本照合（raw ↔ repaired）= 全件合格
- 1,796件すべて PASS、FAIL 0、REVIEW 0。
- 価格・定価（compare_at）・派生の定価・SKU・クーポンタグ・通貨ラベル（USD）が
  原本と全行一致した。
- 通貨根拠は --currency-evidence に、2026-11-18の実カート確認
  （docs/shoepalace-invoice-tax-check-2026-11-18.md、コミット 080d8929、
  米国ストアフロントで全価格がUSD表示だったこと）を記録した。
- 監査レポート全文は collector/price-audit/audit163.json に同梱。

## 結果2: シート照合（reconcile済みシート ↔ repaired）= 261セルの差異
- 差異は HOKA の6商品・87バリアントだけに集中し、パターンは全件同一:
  シート側は価格 $165.00・定価なし、原本スナップショット側は
  価格 $79.97・定価 $165.00。
- つまり、シート作成に使ったスナップショットと全店バッチのスナップショットの
  間で、この6商品のセール状態が変わっている（片方ではセール価格、
  もう片方では通常価格）。修正ロジックの誤りではないと判断するが、
  どちらの時点の価格を正とするかはGPTの検収判断に委ねる。
- なお、この差異があるため監査スクリプトの終了コードは1だった
  （原本照合だけなら終了0相当）。

## 結果3: ネガティブテスト（GPT指定の4件）= 全て検出成功
| 改変 | 終了コード | 検出内容 |
|---|---|---|
| price_minor を1行だけ変更 | 1 | price_minor_mismatch |
| バリアント行を1行削除 | 1 | missing_output_variant |

| coupon_application を確定値に変更 | 1 | unverified_coupon_application |

※入替テストの注意: compare_at と regular は通常同値のため、
入替は price と regular の間で行った（compare と regular の入替は無変化になる）。
