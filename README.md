# nexus-select

NEXUS SELECT — kaitsuke-shop（WordPress + WooCommerce）用カスタムテーマ。
このリポジトリが三者連携のコード正本です。

## 体制
- ChatGPT: 設計とコード作成
- Muse: Local（LocalWP）への適用・動作確認・不具合報告
- Grok: 監査（画像との一致度・既存機能の維持）

## 現在の状態（2026-11-11）
- v0.8.0 + PCホーム改修（SELECTED WORLD）+ KIDSカテゴリー実装
- Localで検証済み。ChatGPT監査・Grok差分確認を通過
- このスナップショットが現行Localテーマと一致します

## 運用ルール
- コードの受け渡しはZIPではなく、このリポジトリ経由で行う
- 変更範囲は原則PCホームのみ（2026-11-11 ユーザー決定）
- 商品ページ（PC・スマホとも）は現行の縦スクロール形式で確定。変更しない
- スマホホームも変更対象外
